# 認証エリアレイアウト設計 (`/(auth)`)

## 1. 役割
Discord ログインが必要なエントリー、ダッシュボード、設定、投稿・編集画面の共通ガードとナビゲーションを定義する。

## 2. 認証・利用条件
- Auth.js セッションを確認し、未ログインの場合はログイン画面へ誘導する。
- `user.is_banned == true` の場合は操作を停止する。
- 最新の利用規約に未同意の場合でも、閲覧とスロット確保は原則許可する。作品投稿、作品編集保存、提出時には再同意導線へ誘導する。

## 3. 共通ナビゲーション
- 左上に `FlameNode` への戻り導線を置く。
- ダッシュボード、エントリー、投稿、設定への導線を配置する。
- 右側にアクティブ X ID スイッチャーを常駐させ、`user.active_x_user_id` を全アクションの既定主体として明示する。
- フッターには利用規約、問い合わせ、トップへ戻る導線を置く。

## 4. X ID の扱い
- アクティブ X ID が未設定の場合、投稿、いいね、ブックマーク、コメント、チャプター作成の前に設定を促す。
- 複数 X ID を保有するユーザーは、クリックで一覧ポップオーバーを開いて選ぶ。候補には Discord名、Xでの表示名、X ID、アイコンを表示し、詳細な管理は `/dashboard/settings` に委ねる。
