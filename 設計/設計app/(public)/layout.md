# 公開エリアレイアウト設計 (`/(public)`)

## 1. 役割
ログイン不要で閲覧できるトップ、作品詳細、作品一覧、イベント、クリエイター、検索、規約、メンテナンス画面の共通レイアウトを定義する。

## 2. 上部メニュー
- 左側に `FlameNode` ロゴを配置し、トップへ遷移させる。
- 主要導線は「作品」「イベント」「クリエイター」「おすすめ」「検索」とする。
- ログイン済みの場合は右側にダッシュボード導線とアクティブ X ID スイッチャーを常駐させる。
- アクティブ X ID スイッチャーは、クリックで一覧ポップオーバーを開いて選ぶ。候補には Discord名、Xでの表示名、X ID、アイコンを表示し、即時切替の誤操作を防ぐ。
- 未ログインの場合はログイン導線を表示し、閲覧導線を阻害しない。

## 2-1. 旧ページ風ヘッダー再現仕様

- トップページと動画詳細ページのヘッダーは、旧 EventArchives の横長固定バー構造をベースにする。正式表記は `FlameNode` に置き換え、色はライト/ダークのテーマトークンに従う。
- デスクトップでは高さ `64px` 前後、ダークモードは深い面色、ライトモードは白または薄いグレーにする。
- 左端のロゴは大きめの英字ロゴとして扱う。2行組み風に見せる場合でも高さはヘッダー内に収め、作品一覧を押し下げない。
- ナビゲーションは英字の大きいラベルと日本語の小さい補助ラベルを縦に組み合わせる。例として `TOP / トップページ`, `LIST / 一覧から探す`, `CREATOR / クリエイターから探す`, `EVENT / イベントから探す` のように、旧ページの見た目を FlameNode の導線へ翻訳する。
- ヘッダー右側にはテーマ切替、ログイン/ダッシュボード、アクティブ X ID スイッチャーを小さくまとめる。テーマ切替は小さなピル型スイッチを基本にし、黄色の点でアクティブ感を出す。
- モバイルでは高さ `42px` 前後に詰め、左にロゴ、右にテーマ切替とハンバーガーを置く。ナビゲーション、ログイン、アクティブ X ID はドロワーまたはポップオーバーに退避する。
- ヘッダーはトップページ、動画詳細、一覧、クリエイター、イベント、規約、メンテナンスを含む全公開ページで表示する。動画詳細のモバイル固定プレイヤー時は、ヘッダー直下にプレイヤーを置き、ヘッダーとプレイヤーが重ならないようにする。

### ヘッダー実装寸法

- デスクトップヘッダーは `display: flex`、左右 padding `28px` から `36px`、gap `32px` 前後を基準にする。
- ロゴ領域は幅 `140px` から `180px`、英字ロゴは `28px` から `32px`、行間は詰める。1行ロゴにする場合も高さ `40px` 以内に収める。
- ナビゲーションの英字ラベルは `20px` から `22px`、太字。日本語補助ラベルは `9px` から `11px`。ナビ項目の横幅は `96px` から `130px` を目安にし、項目間を詰めすぎない。
- 右端操作群は高さ `32px` 以内に収める。テーマ切替は幅 `48px` 前後、高さ `26px` 前後、アクティブ点またはノブに黄色を使う。
- アクティブ X ID スイッチャーは、ヘッダー内ではアイコン、表示名、下向きアイコンのコンパクト表示にする。開いたポップオーバーでは Discord名、X表示名、X ID、アイコン、承認状態を縦リストで表示する。
- モバイルヘッダーは左右 padding `12px` から `16px`、ロゴ `22px` から `24px`、右端操作群はテーマ切替とメニューだけにする。ドロワー内のナビは縦並びで、各項目は英字ラベル、日本語補助ラベル、必要なら Font Awesome アイコンを添える。
- ヘッダーには絵文字を使わない。ハンバーガー、検索、ユーザー、テーマ、外部リンク、設定、ログアウトは Font Awesome などの正規アイコンを使う。

## 2-2. アイコン使用方針

- 公開エリアのヘッダー、フッター、ナビゲーション、テーマ切替、検索、SNS導線、プレイヤー操作、状態表示には絵文字を使わない。
- アイコンは Font Awesome を第一候補とし、既存の実装基盤に合わせて Lucide、Material Symbols、Iconify などの正規 SVG アイコンライブラリを使う。
- X、YouTube、Discord などのブランド導線は、Font Awesome Brands などライセンス確認済みのブランドアイコン、または公式ガイドラインに沿った SVG を使う。
- アイコンだけで意味を伝えず、必要に応じて `aria-label`、ツールチップ、または近接ラベルを付ける。

## 3. フッター
- FlameNode の短い説明、利用規約、イベント開催相談、問い合わせ導線を置く。
- サイト説明は「映像（フレーム）の結節点（ノード）」を基準文言にする。
- トップページを含む全公開ページでフッターを表示する。動画詳細のモバイル固定プレイヤー時も、本文末尾まで到達すればフッターが確認できるようにする。

## 4. 共通表示ルール
- 公開エリアで一般ユーザーに表示する作品は `status == "public"` かつ `is_manual_hidden == false` を基本とする。
- 管理者または作品所有者が閲覧する場合のみ、限定公開や非公開状態の補助表示を許可する。
