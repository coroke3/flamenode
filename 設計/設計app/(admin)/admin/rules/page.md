# 利用規約管理ページ設計 (`/admin/rules`)

## 1. 概要
管理者が FlameNode の利用規約、投稿ガイドライン、イベント開催ガイドラインを編集・公開管理するためのページ。公開ページ `/rules` は、このページで公開された最新バージョンを表示する。

## 2. 権限
- 管理者のみが利用規約の作成、編集、公開、アーカイブを実行できる。
- イベント編集許可者、協力者、通常ユーザーは閲覧できない。
- 公開、アーカイブ、本文変更はすべて `history_logs` に記録する。

## 3. 管理項目
- 規約タイトル
- バージョン名
- 本文 Markdown
- 公開状態（下書き、公開中、アーカイブ）
- 公開日時
- 作成者
- 更新履歴

## 4. 編集フロー
- 新規作成時は下書きとして保存する。
- 公開前にプレビューを表示し、公開後に `/rules` の表示内容が変わることを確認させる。
- 公開済み本文を直接上書きせず、新しいバージョンとして作成して公開する。
- 新バージョン公開時は、既存ユーザーに再同意が必要な状態を付与する。

## 5. 再同意フロー
- 新しい規約が公開された後、ユーザーは次回の作品投稿、作品編集保存、作品提出時に再同意を求められる。
- スロット確保だけでは原則ブロックしない。
- 同意時は `user_tos_consents` にユーザー、規約バージョン、同意日時、同意文脈を保存し、`user.accepted_terms_version_id` を最新にする。
- 再同意が完了するまで、投稿・編集保存・提出の確定ボタンは無効化する。

## 6. 表示
- 左にバージョン一覧、右に編集フォームとプレビューを置く。
- 公開中バージョンは黄色アクセントの状態バッジで示す。
- アーカイブ済みバージョンは誤編集を避けるため読み取り専用で表示する。
