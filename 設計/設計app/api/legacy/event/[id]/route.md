# 旧互換イベント詳細API設計 (`/api/legacy/event/[id]`)

## 1. 役割
外部表示システムが特定イベントの詳細と上映順データを取得するための旧互換 API。

## 2. 認証
- 旧互換 API 用トークンまたは署名ヘッダーで認可する。
- 未認可の場合は 401、存在しないイベントは 404 を返す。

## 3. 入力
- パスパラメータ `[id]` をイベント ID として扱う。

## 4. 出力
- イベント ID、タイトル、説明、画像、開催期間。
- 所属作品一覧、上映順、スロット情報、公開状態。
- 振り返り上映用データが必要な場合は、動画詳細 API または作品配列内の補助フィールドで返す。
- `x_reapply_required` 作品は公開ページでは「調整中」として扱えるが、旧互換 API の上映順・連続再生対象からは除外する。
- `voided` 作品は出力しない。終了済みイベントの履歴枠名義は、管理者が修正した最新表示名を返す。

## 5. 監査
- 外部 API からのイベント取得を記録し、異常なアクセス頻度はレート制限する。
