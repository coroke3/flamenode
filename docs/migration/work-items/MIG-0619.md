## Decisions / budget (ZERO_1102 S1)
- S1 allows one KV read (revocation). The operation-mode mirror is a second KV key, read only on non-exempt paths, at most once per 5 s per isolate (edge `cacheTtl` 30 s). Pages served from a warm isolate still read KV once (revocation) in the common case; D1 stays 0. Recorded here for review; a combined mirror would need a data-model decision.
- `/api/health` only passes the policy; the gateway has no handler for it yet (Hono API MIG-0601 serves it).
- Other Workers (personal / ops / api, SPA, Hono `/api/*`): `edgePolicy.ts` is dependency-free and takes only `Request` and `EdgePolicyEnv`, so the second caller can import it as is; move it to a shared package when that caller exists (U04 decision, not before).
- Host fallback: `request.headers.get("host") ?? url.host` (Workers always has Host; the fallback keeps behaviour where a runtime hides it).
