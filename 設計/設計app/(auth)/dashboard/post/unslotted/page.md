# 【枠なし】過去作品・アーカイブ登録フォーム設計 (`/dashboard/post/unslotted`)

## 1. 概要
旧アーカイブ由来の作品など、タイムテーブル（スロット）に縛られない過去作品や、タイムテーブルの概念が存在しない企画に対して動画情報を登録するページです。
リアルタイムな枠の奪い合いが発生しないため、時間設定はユーザーの手動入力に依存します。

## 2. データベース連携と特徴

*   **`scheduling_type`**: `"manual"` として固定保存します。
*   **YouTube URLの入力優先度**: アーカイブ登録という性質上、動画が既に存在していることが前提となるため、Phase 1/2と分けず、1画面のフォームで「YouTube URL」の入力を促します。
*   **初期ステータスと所有権**:
    *   提出時は `status = "pending"` として保存。
    *   `owner_discord_user_id` にセッションユーザー ID を設定。
*   **セキュリティガード**:
    *   書き込み前に `user.is_banned` をチェックし、BAN 済みユーザーの投稿を拒否する。

## 3. 入力フローとデータマッピング

単一のスクロールフォーム、またはウィザード（ステップ）形式で全ての情報を入力します。

| 項目 (聞き方イメージ) | UI要素 | DB保存先 (`videos`内) | 備考 |
| :--- | :--- | :--- | :--- |
| **対象イベント**<br>「どの企画に参加した作品ですか？」 | プルダウン (複数可) | `video_events` (中間テーブル) | `events` テーブルから取得。 |
| **公開時間**<br>「作品が公開された日時」 | Date/Time Picker | `scheduled_time` | 手動入力によるタイムスタンプ設定。 |
| **YouTube URL**<br>「YouTubeの動画URL」 | テキスト | `youtube_video_id` | URLをパースし、YouTube サムネイルを自動取得。作品サムネイルはアップロードしない。 |
| **参加部門**<br>「個人・団体・混合のどれですか？」 | ラジオボタン | `submission_type` | 団体・混合の場合はメンバー入力欄を表示。 |
| **メンバー登録**<br>「一緒に制作したメンバー」 | インクリメンタルサーチ / CSV入力 | `video_members` (中間テーブル) | 枠あり登録と同じく、名前からID、IDから名前の両方向サジェストを提供。 |

## 4. UI/UXのステート管理

*   **右側プレビューパネル**: 
    *   枠あり登録では「確保するスロット」が表示されていた右側の領域に、アーカイブ登録画面では**「リスト画面に表示される作品カードのプレビュー」**を配置します。
    *   YouTube URL、タイトル、クリエイター名、アイコン画像を入力するとリアルタイムにカードが組み上がり、どのようにアーカイブ化されるかを視覚的に確認できます。
*   **一括登録への拡張性**:
    *   将来的には、イベントIDを固定したまま連続して作品を登録できるよう、「保存して次の作品を登録する」アクションボタンを提供します。
*   **CSV入力とプロンプトコピー**:
    *   メンバー、使用編集ソフト、カスタム質問回答は CSV で貼り付け可能にします。イベント協力者権限の CSV はイベント管理画面で扱います。
    *   各 CSV 入力欄には「CSV作成プロンプトをコピー」ボタンを置き、列名、値の例、出力をCSVのみにする指示をコピーできるようにします。
    *   CSV 取り込み後は、名前・ID サジェストで候補を表示し、未確定行だけ手動補正できます。
