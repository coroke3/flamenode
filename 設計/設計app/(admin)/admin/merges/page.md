# X ID統合管理ページ設計 (`/admin/merges`)

## 1. 概要
ユーザー本人から申請された X ID 統合、統合取消、履歴復元を管理するページ。

## 2. 対象
- 同一 Discord ユーザーに紐づく複数 X ID の統合申請。
- 管理者判断が必要な別所有者間の統合申請。
- 統合済み ID の取消・復元申請。

## 3. 統合処理
- `from_x_user_id` のいいね、ブックマーク、推薦シグナル、ポートフォリオ、コメント、チャプターを `to_x_user_id` へ移す。
- 旧 ID は `x_user_aliases` に保持し、リンク切れや過去クレジットの破壊を避ける。
- 統合完了後は `x_id_merge_requests.status = "done"` とする。

## 4. 取消処理
- 取消は `history_logs` と統合リクエストの前後スナップショットから復元する。
- 取消可能期間、対象データ、復元不能な外部同期済み情報を画面上で明示する。

## 5. 権限・監査
- 本人保有 ID 同士は本人申請を許可し、最終反映は管理者または自動審査で行う。
- すべての承認、却下、取消、復元は `history_logs` に記録する。
