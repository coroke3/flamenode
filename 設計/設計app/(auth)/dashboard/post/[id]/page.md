# 既存投稿編集ページ設計 (`/dashboard/post/[id]`)

## 1. 概要
ユーザーが自身の既存投稿を再編集するページ。通常の作品編集ページ `/dashboard/edit/[id]` と役割を揃えつつ、投稿フロー上の再提出・下書き更新に寄せた導線を持つ。

## 2. 権限
- ログインユーザーが作品所有者であること、またはアクティブ X ID が作品の `creator_id` / `contact_x_id` / `video_members.x_user_id` に該当することを確認する。
- `event_collaborator_permissions` に登録された協力者は、対象作品が属するイベントと許可された `permission_key` に限り編集できる。合作メンバーとして掲載されているだけでは編集権限を持たない。
- 管理者またはイベント編集許可者ではない限り、編集可能フィールド設定そのものは変更できない。

## 3. 入力
- 作品タイトル、YouTube ID、作者表示名、楽曲、クレジット、コメント、メンバー、使用編集ソフト、イベント固有回答。
- 編集可能な項目は `events.editable_fields`、`system_settings.default_editable_fields`、`system_settings.upcoming_editable_fields` の優先順で決定する。
- 協力者が編集する場合は、上記の範囲内でさらに `event_collaborator_permissions.permission_key` を適用する。
- メンバー、使用編集ソフト、カスタム回答は CSV 入力に対応し、「CSV作成プロンプトをコピー」ボタンを表示する。
- イベント協力者の追加や権限変更はイベント管理画面で行い、この画面では現在適用中の権限キーを表示する。
- メンバーの名前/ID入力時は、名前からID、IDから名前の両方向サジェストを行う。

## 4. 保存
- 差分のみ更新する。
- 重大変更がある場合は再審査や差し戻しの可能性を明示する。
- 変更前後は `history_logs` に保存する。
- 最新の利用規約へ未同意の場合、保存前に再同意を求める。再同意が完了するまで保存ボタンは無効化する。
