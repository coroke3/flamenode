- T03: `…a%20b` and `…a b` are the same URL after parsing; the browser resolves the hash to the element id `event-group-a b` (the `/event` Island scrolls with `decodeURIComponent`). Judged equivalent; recorded, not "identical bytes".
- STOP 1 (T04): Workers Static Assets always appends the request query to a `_redirects` destination (`/event?` does not strip it, probed). `/groups?x=1` therefore lands on `/event?x=1`; CURRENT drops it. The `/event` Island ignores unknown keys, but `/groups?q=foo` would apply the filter. A rule cannot express "drop the query": only the gateway Worker can (it builds the Assets request from the path alone).
- Gateway: since MIG-0619 the gateway answers `/groups` and `/groups/{slug}` itself (307, query dropped, same table as `edgePolicy.test.mjs`), so with the gateway in front all rows match CURRENT including the query. The earlier PoC finding (200 / 503) no longer applies; the smoke script now asserts the gateway section too.
- STOP 1 remains only for an Assets-only deployment (no gateway in front): a `_redirects` rule cannot drop the query. With the gateway in front (the plan) everything matches.
