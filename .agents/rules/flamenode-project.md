# FlameNode workspace rule

Read the repository root `AGENTS.md` first. It is the universal project instruction source of truth.

For platform/UI migration work, additionally follow:

1. `docs/migration/AGENT_PROTOCOL.md`
2. `docs/migration/README.md`
3. `docs/migration/STATUS.md`
4. `docs/migration/FUNCTION_INVENTORY.md`

Do not duplicate project architecture or migration rules in Antigravity-specific files.
Do not perform production Cloudflare routing, Remote D1, secret, or deploy mutations without explicit approval.
