# Phase 7: UI/UX・入力UI・表示改善

## 目的

FlameNodeの機能を削らず、表面はシンプルで迷いにくいUIに整理する。上部バー、トップ、エントリー、ダッシュボード、編集フォーム、入力UI、作品詳細を改善する。

## 推奨モデル

- 実装: Sonnet
- 文言候補・CSS崩れ箇所列挙のみ: Haiku可
- 権限UIとサーバー側権限が絡む箇所: Sonnet以上、必要ならOpus

## 対応要求ID

A-1〜A-4、B-4〜B-7、C-1〜C-8、I-1〜I-6、O-1〜O-5、Q-1〜Q-6、J-15

## 必須仕様

### 基本思想

- 機能を削ってまで単純化しない。
- UIはApple的に整理するが、必要な機能は適切な階層に残す。
- 未実装機能は実装済みのように見せない。

### 上部バー

- 基本要素はロゴ、検索、投稿、テーマ切替、X ID切替、アカウント。
- 作品一覧、イベント、クリエイター、おすすめ、ABOUTなどの常時ナビは上部バーから外す。
- 設定、ログアウト、ライブラリ等はアカウントメニューへ寄せる。
- テーマ切替とX ID切替は奥に隠しすぎない。
- アクセントカラーはCSS変数・テーマトークン化する。
- 状態バッジは保留。情報過多を避けつつ必要画面では表示可。

### トップページ

最低限表示:

- 開催日時
- 募集期間
- 残り枠
- イベント概要
- 参加方法の概要

### エントリー・スロット導線

- `スロット確保する` ボタンは直接スロット確保画面へ飛ばす。
- エントリーページは `イベントに参加する` / `過去の自分の作品を投稿する` の2択中心。

### ダッシュボード

- 上部バーはグローバル導線。
- ダッシュボードは概況、状態、次の操作を見せる場所。
- 重複ナビは解消する。

### 編集フォーム

- ページ自体は分けなくてよい。
- 1ページ内で基本情報、楽曲、メンバー等をセクション分割。
- セクションごとに編集可否が分かる。
- 権限がないセクションは見た目で分かる。
- フィールド単位でサーバー側権限チェック。
- YouTube ID変更は重複チェック。
- X ID自由入力で権限を壊せない。
- 自動保存は採用。ただし権限・状態と整合すること。

### 作品詳細・閲覧体験

- メンバー表は初期状態で隠しすぎない。
- 関連動画は作品回遊に役立つ位置へ表示。下部へ押し込みすぎない。
- X ID再申請中作品は一覧・検索から一律排除しない。状態を明示して操作制限。

### 入力UI

- 使用ソフトは既存データを元に選択式へ寄せる。表記揺れは後から統合可能にする。
- クレジット欄は入力例、候補、プレースホルダを出す。
- 時刻入力はピッカー、候補ボタン、連続追加UI、一括入力補助などで楽にする。
- CSVインポートは任意。まず通常操作を楽にする。

### レイアウト

- 横ベタ並びを避け、グリッド、折返し、カード化を使う。
- PC・スマホ両方で最低限操作できる。
- 管理テーブルはカード、フィルタ、要対応表示と組み合わせる。
