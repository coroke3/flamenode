## Scope
- Thin Cloudflare visibility gateway (Recipe R-GATEWAY, Runtime S1: max CPU < 5ms).
- Manifest and denial fence validation without request-time D1 scans or SSR.
- Deterministic fail-closed responses: 404 with `X-Robots-Tag: noindex` for denied / revoked / unmapped routes; 503 for manifest failure; redirects for aliases and legacy paths.
- Strict protection of `/api/auth/*` (gateway bypass / non-interference).
- Out of scope: production Cloudflare Custom Domain or Route changes (requires explicit user approval).
