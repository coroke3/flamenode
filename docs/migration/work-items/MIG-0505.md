| key | normalization (CURRENT) | default | static HTML | owner of the dynamic case |
| --- | --- | --- | --- | --- |
| `q` | trim, 100 chars; fewer than 2 letters/digits = "too short" | empty | default only | MIG-0507 Island |
| `sort` | first 16 chars; `old` / `score`, else `new` | `new` | default only | MIG-0507 Island |
| `page` | 12 digit chars max, 1..209 (`ceil(5000/24)`) | 1 | page 1 only | MIG-0507 Island |
| `event` | trim, 128 chars | empty | default only | MIG-0507 Island |
| `view` | `index` / `compact`, else `grid` | `grid` | grid only | MIG-0507 Island (`ListView` already renders all three) |
`/trending` and `/recommend` read no query keys (CURRENT is ISR, no twin).
