## Producer contract and notes (MIG-0509)
- One `video-detail` key per video = the internal id. CURRENT also writes `videos/{youtubeId}.json`; a producer writing both would produce the same page twice and trip the duplicate-route fence (fail-closed).
- A malformed or non-public record under a manifest-allowed key fails the whole build (fail-closed). The lead aligns this with the event loader's SKIPPABLE policy (skip only NOT_PUBLIC / SNAPSHOT_MISSING) before the production snapshot wiring.
- Free-tier request note: `AccountMenu` calls `GET /api/account/summary?view=presence` once per visitor per page view.
