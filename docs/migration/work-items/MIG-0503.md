## Rules (`apps/site/public/_redirects`)
```
/groups /event 307
/groups/ /event 307
/groups/:slug /event#event-group-:slug 307
/groups/:slug/ /event#event-group-:slug 307
```

The trailing-slash forms exist because the gateway asks Assets for the directory form of a fixed page. The MIG-0502 integration `eventRedirects` appends its generated block to the built file and keeps these lines (tested).

## Findings (local `wrangler dev`, workerd, 2026-10-23; `scripts/migration-groups-redirects.wrangler-smoke.mjs`)
| Request | CURRENT (Next) | Static Assets alone | Behind gateway PoC (MIG-0405) |
| --- | --- | --- | --- |
| `/groups` | 307 `/event` | 307 `/event` (match) | 200, the /event page under `/groups` (mismatch) |
| `/groups/` | 308 `/groups`, then 307 | 307 `/event` | not asked by clients; used internally |
| `/groups/spring` | 307 `/event#event-group-spring` | 307 `/event#event-group-spring` (match, fragment kept) | 503 (mismatch) |
| `/groups/a%20b` (T03) | 307 `/event#event-group-a b` (raw decoded slug) | 307 `/event#event-group-a%20b` | 503 |
| `/groups?x=1` (T04) | 307 `/event` (query dropped) | 307 `/event?x=1` (query kept, mismatch) | 200 |
| `/groups/spring?x=1` | 307 `/event#event-group-spring` | 307 `/event?x=1#event-group-spring` | 503 |
| `/groups/a/b` | 404 | 404 | - |

- T03: `…a%20b` and `…a b` are the same URL after parsing; the browser resolves the hash to the element id `event-group-a b` (the `/event` Island scrolls with `decodeURIComponent`). Judged equivalent; recorded, not "identical bytes".
- STOP 1 (T04): Workers Static Assets always appends the request query to a `_redirects` destination (`/event?` does not strip it, probed). `/groups?x=1` therefore lands on `/event?x=1`; CURRENT drops it. The `/event` Island ignores unknown keys, but `/groups?q=foo` would apply the filter. A rule cannot express "drop the query": only the gateway Worker can (it builds the Assets request from the path alone).
- STOP 2 (gateway): the current gateway PoC does not reproduce the redirects. `/groups` is on `FIXED_PUBLIC_PAGES` but `env.ASSETS.fetch` follows the redirect inside the Worker (answer 200 with /event content, URL unchanged); `/groups/{slug}` is not on the allowlist (503). Fix is in `apps/site/src/gateway/**` (MIG-0404/0405/0406): answer fixed redirects with `redirect: "manual"` and pass `/groups/{slug}` to Assets, or answer the two redirects in the Worker (which also fixes the query). Not changed here.
- Whether the production site will be Assets-only or gateway-first is a Phase 5/8 decision; with Assets only, everything except the query matches.
