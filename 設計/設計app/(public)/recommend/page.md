# おすすめ作品ページ設計 (`/recommend`)

## 1. 概要
FlameNode 内のおすすめ作品を、スコアやユーザーの嗜好に基づいて一覧表示するページ。

## 2. 基本ロジック
- 一般表示は `status == "public"` かつ `is_manual_hidden == false` の作品を対象にする。
- 管理者または所有者向けには限定公開・非公開をフィルタで確認可能にする。
- 既定の並び順は `video_score` 降順。
- `video_score` は FlameNode 内閲覧数、いいね数、YouTube 側再生数を正規化して含めた値を使う。YouTube 側再生数は `log10(youtube_view_count + 1)` を基本に対数化し、アプリ内閲覧数より低い係数にする。
- `x_reapply_required`, `voided`, 非公開、手動非表示の作品はおすすめ対象から除外する。
- 急上昇タブを設ける場合は、直近24時間のアプリ内閲覧数を使う。`economy` 中に閲覧数サンプリングが入る場合、表示値は補正値を使う。

## 3. フィルタ
- 公開、限定公開、非公開のチェックボックスを設計上は持つ。
- 一般ユーザーには公開以外の選択肢を非表示または無効化する。
- ログイン済みユーザーには、視聴履歴、いいね、ブックマーク、合作関係を加味したパーソナライズ推薦を提供する。

## 4. カード表示
- サムネイル、作品名、作者アイコン、作者名、状態バッジを表示する。
- 作品サムネイルは Cloudflare/R2 に保存せず、YouTube ID から `mqdefault.jpg` などの YouTube サムネイル URL を生成する。
