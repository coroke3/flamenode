# 動画詳細ページ設計 (`/[id]`)

## 1. 概要
FlameNode の中核となる作品詳細ページ。YouTube 埋め込みを独自プレイヤーで包み、作品情報、イベント情報、スタッフ、振り返り上映用データ、チャプター、コメント、関連動画、再生リストを一体化して表示する。デザインは旧ページの動画詳細にかなり寄せ、余白より表示密度を優先する。

### 1-1. デザイン参照元

- 旧 EventArchives の動画詳細画面をデザインベースにする。公開上の表記は FlameNode に置き換えるが、大きな動画面、右レールの高密度関連動画、タイトル下の細い区切り線、メンバー表の `No / Name / ID / LINK` 構造、モバイルの上部固定プレイヤーは再現対象とする。黒背景・白文字そのものへ必ず準拠せず、色はライト/ダークのテーマトークンを正とする。
- 追加機能であるチャプター点表示、時間付きコメント、再生リスト、X ID 再申請、スロット取り直し、Cloudflare コストガード表示は、旧ページの密度を壊さないように、小さな帯、タブ、ポップアップ、右レール内 UI として組み込む。
- ダークモードでは深い背景、ライトモードでは白基調を使う。プレイヤー枠と独自コントロールは映像視認性を優先して高コントラストにし、ページ全体の色はテーマトークンに従う。

## 2. ルーティング
- `[id]` は UUID と YouTube 動画 ID の両方を受け入れる。
- UUID でアクセスされた場合でも YouTube ID が登録済みなら、正規 URL は YouTube ID 形式へ統一する。
- 対象作品が存在しない、または一般公開不可の場合は NotFound または権限説明画面を表示する。
- 対象作品が `x_reapply_required` の場合、一般閲覧者、ログイン本人、管理者/イベント編集許可者で表示を分ける。一般閲覧者には「調整中」の簡易表示、本人には枠取り直しと X ID 再申請ウィザード導線、管理者/イベント編集許可者には旧 X ID 履歴、対応期限、監査ログ導線を出す。
- 対象作品が `voided` の場合、一般閲覧者には NotFound 相当、本人には通知から遷移した場合だけ「不備」の説明、管理者には監査・復旧判断用の確認画面を表示する。通常の本人ダッシュボードや公開導線からは出さない。

## 3. レイアウト
- 通常PCでは左側メインカラムに独自プレイヤー、タイトル、作者情報、本文、スタッフ/クレジットを配置する。
- 右側レールにイベント情報、関連動画、再生リストを配置する。
- メイン動画を最上部に置き、その下に作者アイコン・作者名・SNS導線・投稿日時を横並びで並べる。
- ライトモードではページ全体を白基調にし、プレイヤー枠と独自コントロールだけ高コントラストにする。
- 作品ごとの大きな枠や余白は最小限にし、情報量と関連動画の表示数を確保する。
- ウルトラワイドでは独自レイアウトを使い、左に作品タイトル・投稿者情報・チャプター一覧、中央に動画プレイヤー、右に関連動画・再生リストを置く。

### 3-0. 旧ページ風の画面構成

- デスクトップ標準では、ヘッダー直下から動画面を大きく見せる。左側にプレイヤーと作品情報、右側に関連動画レールを置き、右レールはページ上部から始める。
- プレイヤーの上には作者アイコン、作者名、作品タイトルの短縮表示、音量、字幕、設定などの小アイコンを重ねる。これらは独自プレイヤーの操作レイヤーとして扱い、非操作時にはプレイヤーを邪魔しない透明度にする。
- プレイヤー中央には半透明の丸い再生/一時停止ボタンを表示する。ボタンは映像の中心に置くが、操作後は短時間で消える。
- プレイヤー下部には現在時刻、総時間、現在チャプター名、シークバー、チャプター点を横一列で表示する。チャプター点は旧ページの細かい点線風の見え方を参考にしつつ、クリック可能領域は広めに確保する。
- プレイヤー下の小操作列には、共有、ブックマーク/あとで見る、関連動画パネル、YouTubeで開く導線を置ける。旧ページの「その他の動画」「YouTube」風の導線を、FlameNode の再生リスト・セーブ・外部視聴へ置き換える。
- 右レールはサムネイルとタイトルを詰めて縦に並べる。サムネイル幅は行全体の `42%` 前後、タイトル側は `54%` 前後を目安にし、1行の高さを抑える。作者名は小さく、説明文は出さない。
- モバイルではヘッダー直下にプレイヤーを固定し、右レールは本文下へ回す。プレイヤー直下にタイトル、作者行、イベント前後カード、メンバー表が続く。関連動画の一部はプレイヤー直下へ先出ししてもよいが、タイトルと警告導線を隠さない。
- ウルトラワイドでは、左カラムにタイトル、作者行、警告、チャプター/コメントタブ、本文概要を置き、中央カラムにプレイヤー、右カラムに再生リストと関連動画を置く。3カラム時も旧ページの右レール的な高密度リストは維持する。

### 3-0-1. 旧資料不要の動画詳細完成イメージ

旧ページ資料がなくても再現できるよう、動画詳細ページの完成形を次のように固定する。

- **通常PC全体**: ページ本体は左右余白 `2.5%` から `5%`。左メインと右レールの2カラム。右レールは幅 `320px` から `360px`。メインカラムは残り幅を使い、プレイヤーを最上部に置く。
- **プレイヤー比率**: プレイヤーは常に `16:9`。メインカラム幅いっぱいに置き、外側に装飾カードや太い枠を付けない。
- **プレイヤー上部オーバーレイ**: 左上に作者アイコン `32px` から `40px`、作者名、短縮タイトルを横並びで置く。右上に音量、字幕、設定などの Font Awesome 相当アイコンを `20px` から `24px` で並べる。非操作時は透明度を下げる。
- **中央操作**: 再生/一時停止は中央の半透明円ボタン。直径はデスクトップ `56px` から `72px`、モバイル `44px` から `56px`。アイコンは絵文字ではなく正規 SVG。
- **下部操作**: 左に現在時刻/総時間、中央から右にシークバー、右側に現在チャプター名、全画面、YouTubeで開く導線を置く。コントロール高さは `44px` から `56px` に収める。
- **シークバー**: 高さは通常 `3px` から `5px`、ホバー/フォーカス時だけ太くする。チャプター点は直径 `5px` から `7px`、クリック判定は最低 `20px` 四方を確保する。
- **プレイヤー下操作列**: 共有、ブックマーク/セーブ、再生リスト、YouTubeで開く導線を小さなピルまたはアイコンボタンで横並びにする。ボタン高さは `32px` から `40px`。
- **タイトル領域**: プレイヤー直下にタイトルを置く。デスクトップは `28px` から `34px`、モバイルは `18px` から `21px`。タイトル直下に細い境界線を1本置く。
- **作者行**: 作者アイコン `40px`、作者名、X/YouTube/外部リンクアイコン、公開日時を1行にする。公開日時はデスクトップで右寄せ、モバイルでは折り返し可。
- **警告帯**: `x_reapply_required`、YouTube同期失敗、規約再同意などの重要状態は、タイトルと概要の下に高さ `36px` から `52px` の細い帯で出す。本文や関連動画の下に置かない。
- **イベント前後パネル**: イベント名、種別ラベル、前の作品/次の作品を低いパネルにまとめる。サムネイルは `120px` から `170px` 幅、タイトルは2行まで。
- **メンバー表**: `No / Name / ID / LINK` の4列。行高さは `40px` から `52px`。ID列には小さなアイコンと X ID を置く。モバイルでは横スクロールを許可する。
- **右レール**: 最上部に再生リストパネル、その下に関連動画を並べる。関連動画行は高さ `74px` から `96px`、左サムネイル幅 `42%`、右テキスト幅 `54%`。タイトル2行、作者名1行、説明文なし。
- **右レール件数**: 標準15件、最大30件。ウルトラワイドでは右レール内を2列化してもよいが、各行のサムネイル比率とタイトル2行制限は守る。
- **ウルトラワイド**: 幅 `1800px` 以上または `20:9` より横長では3カラム。左 `360px` から `460px` にタイトル、作者、警告、チャプター/コメントタブ。中央はプレイヤー。右 `360px` から `520px` に再生リストと関連動画。左右カラムだけ縦スクロール可。
- **モバイル**: ヘッダー直下に `16:9` プレイヤーを固定する。本文側にはプレイヤー高さ分の余白を入れ、タイトル、警告帯、作者行、イベント前後、チャプター/コメント、メンバー表、関連動画の順に並べる。
- **状態別密度**: 再申請、調整中、コストガードなどの追加情報は、細い帯、タブ、ポップアップで出す。大きな説明カードを常設しない。
- **禁止事項**: 関連動画を大きなカードにしない。説明文を右レールに出さない。コメント欄をYouTube風の長いスレッドとして常設しない。絵文字を操作アイコンに使わない。

## 3-1. 詳細配置仕様

### 全体
- ページ本体は幅 `90%`、左右 `5%` 余白を基本にする。幅 `1300px` 未満では `95%`、左右 `2.5%` に広げる。
- PC ではメインカラムと関連レールの2カラムにする。
- 関連レール幅は `350px`。メインカラム幅は `calc(97% - 350px)` を目安にし、左右にごく薄い余白を残す。
- 画面幅 `1000px` 未満では1カラムにし、関連レールは動画本文の下に回す。
- 画面幅 `700px` 未満では本文、作者情報、イベント情報、テーブル、関連レールの幅を約 `93%` にして中央寄せする。
- 作品ごとの独立カード枠は使わず、線、余白、文字サイズで区切る。ライトモードでは白背景を維持し、プレイヤー枠だけ黒くする。

### プレイヤー
- プレイヤーは `16:9` を厳守し、横幅いっぱいに表示する。
- デスクトップでは上に `34px` 前後の余白を置く。モバイルでは上余白を0に近づける。
- 縦長モバイルでは、プレイヤーを上部に固定表示する。比率は必ず `16:9` とし、本文の先頭に同じ高さのダミー余白を作り、コンテンツがプレイヤーに隠れないようにする。
- ウルトラワイドでは、中央カラムをプレイヤー専用に近い扱いにし、左カラムにタイトル、作者行、主要メタ情報、チャプター一覧を置く。右カラムは関連動画と再生リストを置き、左/右カラムは縦スクロール可能にする。
- ダークモードのプレイヤー周辺は深い背景へ自然に馴染ませる。プレイヤー外枠や装飾カードは付けず、動画面そのものを主役にする。
- ライトモードでもプレイヤー枠と操作レイヤーは高コントラストにし、視認性を維持する。ページ全体は白基調のままにし、シアター風の暗い面をページ全体には広げない。

### タイトル・作者行
- タイトルはプレイヤー直下に置く。デスクトップでは `32px` 前後、モバイルでは `19px` 前後。
- タイトル下には細い境界線を1本入れ、情報の開始点を示す。過度なカード枠は使わない。
- 作者行は横並び。アイコン `40px` 円形、作者名、X/YouTube などの小アイコン、公開日時を置く。
- 公開日時はデスクトップでは右寄せ、モバイルでは小さくして折り返しを許可する。
- `x_reapply_required` や YouTube 同期失敗など、対応が必要な警告はタイトルと概要の直下に固定表示する。旧ページ寄せの高密度 UI でも埋もれないよう、黄色またはイベントアクセントの細い帯と短い説明で見せる。ウルトラワイド時は左カラム内で sticky にし、モバイル固定プレイヤー時はプレイヤー直下にコンパクトな CTA 帯として表示する。
- タイトル下の水平線は薄い境界線1本で情報の区切りを作る。大きなカードや背景面でタイトルを囲まない。
- 作者行の X/YouTube アイコンは小さく、作者名の横へ詰める。公開日時は右側へ寄せ、モバイルでは改行を許す。

### 本文情報
- 楽曲、クレジット、紹介コメント、制作コメント、振り返りコメントを本文エリアに表示する。
- 本文は長くなりやすいため、見出しは小さく、余白は `12px` から `20px` 程度に抑える。
- メンバー表は、No、Name、ID、LINK の4列を基本にする。
- メンバーアイコンは `30px`、行の padding は `12px 15px` 程度。モバイルでは文字サイズを落として横スクロールを許可する。
- メンバー表は旧ページの表組みを再現する。文字色と交互行の背景はテーマトークンに従い、ダーク/ライト双方で読みやすいコントラストを保つ。
- メンバー表の `ID` 列は X ID とアイコンを近接させ、`LINK` 列は X などの小アイコンまたは短いテキストリンクで見せる。列幅が足りない場合は横スクロールを許可し、文字を無理に潰さない。

### イベント情報
- 作品が所属するイベントは、本文内に横並びまたは折り返しカードとして表示する。
- イベントカードはアイコン、イベント名、短い説明、イベント詳細へのリンクを含む。
- 各イベントカードの下に「前の作品」「次の作品」のナビゲーションを置く。
- 前後作品ナビゲーションは左右2分割。サムネイル幅 `160px`、タイトル2行まで。モバイルでは縦並びにし、サムネイル幅 `100px` 程度にする。
- イベントアクセントカラーがある場合、イベントカードの境界線、前後作品ラベル、リンクホバーにその色を使う。
- イベント前後ナビゲーションは旧ページの低いパネル風を参考にする。ダーク/ライトそれぞれの面色に、イベント名、種別ラベル、前後作品サムネイルを低い高さで収める。

### 関連レール
- PC では右レールに関連動画を縦に並べる。各項目は横並びで、左に `42%` のサムネイル、右に `54%` のタイトル・作者名を置く。
- 関連項目の上下余白は `10px` 前後。サムネイルは `16:9`。タイトルは2行以内、作者名は小さく表示する。
- ウルトラワイドでは関連レールを複数列にしてもよい。1項目幅は `calc(50% - 10px)` を目安にする。
- 関連レールは「同じ作者」「イベント前後」「メンバー関連」「同じ楽曲」「おすすめ」などを混在させるが、見た目は同じコンパクトなリストに統一する。
- 関連レールの最上部に再生リスト風 UI を差し込めるようにする。対象は「企画の動画を順番に再生」「自分のいいね作品を順番に再生」「自分のブックマーク/セーブ作品を順番に再生」とする。
- 再生リスト風 UI は YouTube の再生リストに近く、現在再生中の行、次に再生される行、連続再生 ON/OFF、一覧を閉じる操作を持つ。
- 関連動画は「同じ作者」「同じイベント」「おすすめ」などの見出しでセクション分けし、単なる人気順ではなく文脈近さを優先する。
- 旧ページの右レール密度を基準にし、関連動画1件あたりの縦幅を抑える。タイトルは2行まで、作者名は1行、サムネイルの角丸は控えめにする。
- モバイルで関連動画を本文下に回す場合も、サムネイルを左、タイトルを右にした横長行を基本にする。ただし画面幅が狭い場合はサムネイル幅を `42%` 程度に固定してタイトルを2行省略する。

### レスポンシブ基準
- `1300px` 未満: 全体幅を `95%` にする。
- `1000px` 未満: メインと関連を1カラム化する。
- `700px` 未満: プレイヤー上余白を削り、タイトル `19px`、本文 `11px` から `12px` 程度へ詰める。
- `500px` 未満: イベント前後ナビゲーションは縦並びにする。
- `20:9` より横長: 左に作品情報とチャプター一覧、中央にプレイヤー、右に関連動画と再生リストを置く。縦スクロールを最小化し、中央プレイヤーの見通しを優先する。

## 4. 独自プレイヤー
- YouTube iframe を直接露出させず、FlameNode の独自コントロール層で包む。
- 再生、一時停止、音量、全画面、現在時刻、シークバー、コマ送りを提供する。
- マウスが停止した場合、またはプレイヤー領域外へ出た場合は、再生バー等の透かし UI を即座に非表示にする。
- キーボード操作はスペースで再生/停止、左右キーでシーク、`,` / `.` で 1/30 秒コマ送りを想定する。
- イベント別アクセントカラーがある場合、プレイヤー進捗・フォーカス・アクティブ状態はその色を優先する。未設定時は FlameNode の鮮やかな黄色を使う。
- `video_chapters.show_on_player_bar = 1` のチャプターを、シークバー上の小さな点として表示する。点の位置は `chapter_time / duration` で計算し、`marker_kind = 'chapter'` の点を最優先で表示する。
- チャプター点は、ホバー、タップ長押し、キーボードフォーカス時に時刻とラベルを表示する。クリックまたは Enter/Space でその時刻へシークする。
- 点そのものは控えめに見せるが、実際のクリック/タップ判定領域は広めに取り、モバイルでも誤操作しにくくする。
- 点が密集する場合は、チャプター点を残し、通常コメント由来の点は縮約または表示切替に回す。モバイルでは一覧 UI で細かな点を補完する。
- 2秒以内に密集する点は1つの点へまとめ、ホバー、タップ、キーボードフォーカス時に複数候補をリスト展開する。
- 非公開チャプターは本人と管理者だけ半透明の点として表示する。範囲外チャプターは一覧で「無効（範囲外）」としてグレーアウトし、再生バーには出さない。
- モバイルでもコマ送り操作を必須にする。
- 再生バー上のプレビューは任意機能とする。YouTube から任意時刻のフレーム画像を安定して取得できない場合、フレーム画像プレビューは出さず、時刻、ラベル、投稿者アイコン、周辺コメント数を表示する軽量なテキストプレビューで代替する。Cloudflare/R2 にプレビュー画像は保存しない。
- 埋め込み不可または年齢制限で iframe 再生できない場合は、プレイヤー中央に YouTube サムネイルと「YouTubeで視聴する」外部リンクを表示し、タイトル直下にも同じ導線を置く。
- プレミア公開待ちで公開予定時刻が取得できる場合のみ、簡易テキストのカウントダウンを表示する。

## 5. 振り返り上映用データ
- 振り返り上映用データは本文内に常設せず、「振り返りデータ」ボタンからポップアップで表示する。
- ポップアップには `intro_comment`, `outro_comment`, `closing_comment`, `highlights`, `production_story`, `used_software`, `custom_answers` を整理して表示する。
- 上映中の視聴体験を邪魔しないため、ポップアップは閉じるとプレイヤー操作へ即復帰できる。

## 6. チャプターとコメント
- YouTube 風のスレッド型コメント欄ではなく、ニコニコ動画寄りの時間軸反応として扱う。ただし標準 UI は一覧中心にし、コメント欄感を強く出しすぎない。
- チャプターは `video_chapters` に保存し、コメント本文は `video_comments` に保存する。コメントは基本的に `video_comments.chapter_id` でチャプターへ紐づける。
- チャプターは `marker_kind` で通常反応、チャプター、振り返り用、システム由来を区別する。再生バー上に出すチャプターは `marker_kind = 'chapter'` とし、既定で `show_on_player_bar = 1` にする。
- 投稿主体は必ず `user.active_x_user_id` に紐づける。
- ユーザーは現在の再生秒数を自動取得でき、手入力で任意の秒数へ修正できる。
- 自分が設定したチャプター一覧を確認できる UI を置く。
- チャプターは公開/非公開を切り替えられる。公開チャプターは他ユーザーも閲覧でき、非公開チャプターは本人と管理者だけが見られる。
- 自分の非公開チャプターは本人の再生バーには控えめな点として表示してよい。他ユーザーには公開チャプターとチャプター点のみを表示する。
- コメントはチャプターに紐づけて投稿できる。チャプターをクリックすると該当時刻へシークする。
- コメント本文は短文を前提にし、長いスレッドや返信階層は標準機能にしない。
- チャプターとコメントは「チャプター」「コメント」のタブで分ける。ニコニコ動画風の流しコメントは将来の任意機能として扱い、既定は OFF にする。
- YouTube IDを差し替えて既存チャプターの秒数が動画長の範囲外になった場合は、範囲外チャプターとして非表示にせず、一覧上で無効表示にする。

## 6-1. 状態別表示

- **通常公開**: プレイヤー、タイトル、作者、本文、チャプター、関連動画を通常表示する。
- **`x_reapply_required` / 一般閲覧者**: 作品全体を完全には露出せず、「調整中」と短く表示する。コメント、チャプター、関連動画、再生リストには含めない。
- **`x_reapply_required` / ログイン本人**: タイトルと概要の下に、枠取り直しを先に行うウィザード導線を固定表示する。続けて X ID 再申請または既存承認済み X ID への付け替えを選べる。作品本文、YouTube URL、合作メンバー、クレジットは編集可能にする。
- **`x_reapply_required` / 管理者・担当イベント編集許可者**: 旧却下 X ID、再申請期限、再取得枠、通知状態、`history_logs` への導線を確認できる。公開側には旧 X ID を出さない。
- **`voided` / 一般閲覧者**: NotFound 相当の扱いにする。
- **`voided` / ログイン本人**: 本人向けには通知から遷移した場合のみ「不備」と表示し、詳細文は通知内だけで見せる。通常一覧やギャラリーには出さない。
- **`voided` / 管理者**: 監査確認、イベント別・理由カテゴリ別統計、必要な復旧判断のための管理表示に限定する。復旧は管理者専用で、イベント編集許可者は復旧要請のみ行える。

## 7. 関連動画ロジック
- 関連表示は以下を候補として重複排除する。
  - 同一作者の作品
  - 現在作品の合作メンバーが作者またはメンバーとして関わった作品
  - 同一楽曲、同一クレジットの作品
  - 所属イベント内の前後作品
  - `video_score` 上位作品
  - ランダム補完
- 表示前に現在作品を除外し、公開不可作品は一般ユーザーへ表示しない。
- 候補は人気度と文脈近さを組み合わせて左右または右レールへ分配する。比率は `video_score` 40%、文脈近さ60%を目安にする。

### 7-1. 関連動画の抽出優先度
- すべての候補から現在作品を除外し、同じ動画 ID の重複を1件にまとめる。
- 優先度1: 同一作者の作品。公開作品なら最大3件、限定/非公開を管理者が見ている場合は最大4件。
- 優先度2: 現在作品の作者が、別作品の `video_members` に含まれる作品。最大2件。
- 優先度3: 現在作品の合作メンバーが作者になっている作品、または別作品のメンバーに含まれる作品。メンバー数に応じて1人あたり1から2件。
- 優先度4: 同一楽曲、同一クレジットの作品。各最大3件。
- 優先度5: 所属イベント内で上映順が前後の作品。イベントごとに前後1件ずつ。
- 優先度6: `video_score` 上位作品から最大2件。
- 優先度7: 候補数が足りない場合、公開作品のランダムまたは新着で補完する。
- 最終表示件数は右レールで標準15件、最大30件にする。超横長画面では2列化して最大件数まで表示してよい。

### 7-2. 関連動画カード表示
- 関連動画は大きなカードではなく、左にサムネイル、右にタイトルと作者名を置く横長ミニカードで表示する。
- サムネイル、タイトル、作者名のみを基本にし、説明文や長い分類情報は出さない。
- 「前の作品」「次の作品」は通常の関連動画とは別枠にし、イベント文脈が分かるラベルを付ける。

## 8. SEO
- タイトルは `{作品名} - {作者名} | FlameNode`。
- OGP 画像とカード表示には YouTube サムネイルを利用する。作品サムネイルを Cloudflare/R2 に保存しない。
