# ユーザー設定ページ設計 (`/dashboard/settings`)

## 2. デザイン方針

- **コンセプト**: "Personalized Command" (自分だけの空間を整える)
- **レイアウト**:
    - **設定ナビゲーション**: プロフィール、連携アカウント、カスタムページ、テンプレート、プライバシー、エクスポート等を切り替える垂直タブ。
    - **メインフォーム**: 選択された項目の設定フォームを右側に配置。
- **視覚演出**: `FlameNode-Design-System.md` のデザイン指針に従い、未保存の変更がある場合は画面下部に黄色アクセントのフローティング保存バーを表示します。
- **セキュリティUI**: Discord ID やトークン等の機密情報はデフォルトでマスク（伏せ字）表示し、ホバーまたはクリック時のみ表示する配慮を組み込みます。
- **体験**: アカウント連携（Discord/X）の状態を、ロゴアイコン付きの大きな Glass Tile バッジで示し、接続・解除の状態を直感的に把握させます。

## 3. 目次・機能一覧
1. **プラットフォーム連携状態表示・変更機能**: Discord/X等のOAuth連携管理
2. **X ID複数管理機能**: 連携済みIDの追加/選択/解除
3. **アクティブX ID切替機能**: 保存先の既定X IDを切り替え
4. **X ID統合（マージ）機能**: 旧ID→新IDの統合
5. **基本プロフィール入力機能**: クリエイター名と各SNSリンクの登録
6. **カスタムページ編集機能**: HTML/CSS入力とプレビュー
7. **テーマ・テンプレート管理機能**: デフォルトテーマの選択
8. **AI用プロンプトコピー機能**: ショートコード仕様のワンクリックコピー
9. **デフォルトアバター・背景画像設定機能**: プロフィールのビジュアルカスタマイズ
10. **アカウント設定・退会機能**: プライバシー設定およびデータ削除処理

## 4. 各機能の詳細解説

### 1. プラットフォーム連携状態表示・変更機能
*   **役割:** 現在ログインしているアカウントが、どのプロバイダ（Discord, X/Twitterログイン用プロバイダ）と紐づいているかを示し、追加連携を行わせる。
*   **内部ロジック:** Auth.js の `useSession` と D1 の `user` に基づいて現在の連携状態を表示する。

### 2. X ID複数管理機能
*   **役割:** 複数のX IDを保持し、作品の編集権限やクレジット入力に活用する。
*   **内部ロジック:**
    *   連携済みID一覧を表示し、デフォルトIDを選択可能にする。
    *   新規追加時は `x_users` を作成または既存IDへ統合する。
    *   連携したX IDに紐づく既存作品の編集権限を付与する。
    *   **承認待ち**: `approval_status == "pending"` でも投稿申請や下書き作成は可能。

### 3. アクティブX ID切替機能
*   **役割:** いいね/ブックマーク/投稿などの保存先X IDを明示する。
*   **内部ロジック:**
    *   `user.active_x_user_id` を更新。
    *   グローバルステートで現在のX IDを保持し、アクション実行時に参照。
    *   **グローバル常駐:** 切替 UI は設定画面内だけでなく、上部メニューバーへ常時配置する。設定画面では詳細管理、メニューバーでは日常的な切替を担う。
    *   **表示順:** 一覧ポップオーバーでは「承認済み」→「再申請中」→「承認待ち」の順で表示し、Discord名、X表示名、X ID、アイコンを並べる。
    *   **再申請中の固定:** X ID 再申請ウィザード開始後は、開始時点の再申請対象 ID を優先・固定する。途中でアクティブ X ID を切り替えても、再申請対象を勝手に変更しない。

### 4. X ID統合（マージ）機能
*   **役割:** 旧X IDのデータを新X IDへ統合する。
*   **内部ロジック:**
    *   統合対象を選択し、`x_id_merge_requests` を作成。
    *   承認後に Like/Bookmark/recommendation_signals/custom_pages/comments/時間付きコメントを新IDへ移行。
    *   旧IDは `x_user_aliases` に履歴として保持。
    *   **本人保有IDの統合:** 同一 Discord ユーザーに紐づく複数 X ID は、ユーザー本人が統合元と統合先を選べる。
    *   **取消:** 統合後に戻す場合は `history_logs` と統合リクエストのスナップショットから復元する。完全復元できない外部同期済みデータがある場合は、取消確認画面で明示する。
    *   **再申請との競合:** X ID 再申請と統合が同時に発生した場合は再申請を優先する。統合処理は一時停止し、主体復帰後に再開する。
    *   **却下IDの扱い:** 却下された X ID は正規の alias 履歴として保持しない。公開ページにも出さず、管理画面の監査履歴としてのみ扱う。

### 5. 基本プロフィール入力機能
*   **役割:** サイト内全体（`/user/[id]` など）で使われる基本となる表示名やリンクを更新する。
*   **内部ロジック:** `user` テーブル（設定申請）および `x_users` テーブル（実際のプロフィール）に対するフォーム。
    *   `x_name` (Xの表示名)
    *   `id` (XアカウントのID、@以降)
    *   `youtube_channel_url` (YouTubeチャンネルのURL)
    *   `profile_text` (プロフィール文)

### 6. カスタムページ編集機能
*   **役割:** Tumblrのカスタムページのように、HTML/CSSを自由記述できるポートフォリオを提供する。
*   **内部ロジック:**
    *   `<style>` を含むHTML/CSSを入力可能。
    *   ライブプレビューと下書き保存を用意。
    *   ショートコードをプリプロセスして差し込む。
    *   ポートフォリオは全員必須ではなく、本人が有効化した場合のみ `/user/[id]/portfolio` に公開する。未有効の場合は通常プロフィールだけを表示する。

### 7. テーマ・テンプレート管理機能
*   **役割:** デフォルトテーマの構成や作成者情報を管理する。
*   **内部ロジック:**
    *   テーマカードを一覧表示し、適用/解除を切り替える。
    *   テンプレートの作成者情報・ライセンスを表示する。

### 8. AI用プロンプトコピー機能
*   **役割:** LLMでカスタムページを生成したいユーザー向けに、ショートコード仕様を提示する。
*   **内部ロジック:**
    *   「AI用プロンプトをコピー」ボタンでクリップボードに出力。
    *   ショートコードの一覧、サンプル、入力制約を含む。

### 9. デフォルトアバター・背景画像設定機能
*   **役割:** 作品に紐づくアイコン候補から、X ID の代表アイコンを選べるようにする。
*   **内部ロジック:** アイコンは基本的に作品に紐付く。候補は「一番最初の作品」「最新の個人作品」「個人作品がなければ複数人作品」「作品に登録されているアイコン候補」から選べるようにする。
*   **アップロード:** Cloudflare にアップロードする画像はアイコン画像のみ。元ファイル上限は1ファイル8MB、保存前に 250x250 WebP へ圧縮する。

### 10. アカウント設定・退会機能
*   **役割:** ユーザーに自身のデータに対する主権を持たせる必須機能（退会処理）。
*   **内部ロジック:** 
    *   **退会処理:** 「アカウントを削除」リンクよりモーダル展開での最終確認。承認後、D1 からのカスケード削除（`ON DELETE CASCADE`）または論理削除（`is_deleted = 1`）を SQL で実行する。

## 4. 詳細UIロジックとステート管理

### 4-1. リンク済みプロバイダのデタッチ
*   **認証管理**: Auth.js セッションと D1 に基づき、一度連携した X や Discord を解除する機能。全てのプロバイダを解除してログイン不能になることを防ぐため、「最低1つのログイン手段を残す」バリデーションを設けます。

### 4-2. ユーザーID (Slug) の変更制限
*   **永続性**: プロフィールURL `/user/[id]` に使用するユーザーIDを変更可能にする場合、検索インデックスや過去のリンク切れを防ぐため、「変更は90日に1回まで」などのクールダウン期間をロジックで制御します。

### 4-3. プライバシー・プロテクション
*   **機密情報**: 設定画面上の Discord ID や X のアクセストークン等（必要であれば）は、デフォルトで伏せ字（マスク）表示にし、「表示」ボタンを押した際のみ平文で表示する高いセキュリティ意識の UI を採用します。

### 4-4. 一括データエクスポート
*   **GDPR準拠**: ユーザーがこれまでに投稿した動画リンク、獲得ポイント、連携情報を JSON 形式で一括ダウンロードできる機能を配置し、データのポータビリティを確保します。
