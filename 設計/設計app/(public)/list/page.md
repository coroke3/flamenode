# 作品一覧・検索ページ設計 (`/list`)

## 1. 概要
過去から現在までにFlameNodeへ投稿されたすべての作品を一覧表示し、多様な条件で検索・絞り込みを行うためのページです。

## 2. デザイン方針

- **コンセプト**: "Cinema Gallery" (並び、探す愉しみ)
- **レイアウト**:
    - **フィルターセクション**: 画面上部またはメインエリアの冒頭に、チェックボックス群（公開、限定公開、非公開）を横並びで配置。
    - **作品グリッド**: 画面幅に合わせたレスポンシブなグリッドレイアウト。
    - **カード構成**:
        - メインサムネイル。
        - 下部に作品タイトル。
        - その下にクリエイター名（アイコン＋名前のペア）。
        - 右下等にステータス（限定公開/非公開）のバッジ/アイコンを表示。
- **視覚演出**: `FlameNode-Design-System.md` の `--bg-surface` と `--border-subtle` をベースに、ホバー時は黄色の `--accent-primary` の薄いグローを適用。非公開作品にはグレースケールや鍵アイコンなどで視覚的な区別を設けます。
- **体験**: チェックボックスの操作が即座にリストに反映されるリアクティブなフィルタリング。


## 3. 目次・機能一覧

1. **フリーワード・キーワード検索機能**: 作品名やクリエイター名での絞り込み
2. **ステータスフィルタリング機能**: 公開・限定公開などの公開状態による絞り込み
3. **並び替え機能**: 新着順やおすすめ順などのソート
4. **イベント絞り込み機能**: 特定のイベントに紐づく作品の抽出
5. **無限スクロール / ペジネーション機能**: データ全量の段階的読み込み
6. **YouTubeサムネイル表示機能**: Cloudflareに保存せずYouTubeサムネイルを利用

## 4. 各機能の詳細解説

### 1. フリーワード・キーワード検索機能

- **役割**: 入力されたテキストに基づき、観たい作品を探し出す中核機能。
- **内部ロジック**: 検索ボックスに入力された文字列を元に、D1の `videos` テーブルに対し `LIKE '%query%'` クエリによる高速検索を行う。※D1 は現時点で FTS5 をサポートしていないため、KV インデックスによる補完も検討する。

### 2. ステータスフィルタリング機能

- **役割**: 「公開」「限定公開」など、作品のステータスに応じた表示切り替え機能。
- **内部ロジック**: チェックボックス（公開・限定公開・非公開）のトグルで切り替え。
  - **既存再現**: 3つのチェックボックス（公開・限定公開・非公開）を設けますが、一般ユーザーの画面では「限定公開（差し戻し中）」や「非公開」の選択肢は非表示、または操作不能とします。
  - 一般ユーザーには `status == "public"` かつ `is_manual_hidden == false` の作品のみを表示します。管理者または作品所有者が自身の作品を確認する場合に限り、他のステータスも表示可能にします。
  - `x_reapply_required` は通常一覧には出さず、イベント詳細ページでは「調整中」として扱う。`voided` は公開一覧、検索、スコア順表示、急上昇、ランキングから除外する。

### 3. 並び替え機能

- **役割**: ユーザーが求める指標順にリストを並べ直す機能。
- **内部ロジック**: プルダウン等で「新着順 (`scheduled_time`降順)」「古い順 (同昇順)」「おすすめ順 (`video_score`降順)」のクエリを再発行する。
- **急上昇**: 急上昇タブを設ける場合は直近24時間のアプリ内閲覧数を使う。サンプリング中は補正値を表示し、`voided` や `x_reapply_required` は完全除外する。

### 3-1. 旧資料不要のカード再現

- 作品カードはサムネイル、作品タイトル、作者アイコン、作者名、状態バッジを含める。
- サムネイルは YouTube ID から `mqdefault.jpg` などの YouTube サムネイル URL を生成して表示する。作品サムネイルは Cloudflare/R2 に保存しない。
- 一般ユーザーには公開作品のみ、管理者または所有者には必要な範囲で限定公開・非公開作品を見せる。
- カードは `16:9` サムネイルを上に、タイトル2行、作者行1行の縦積みにする。デスクトップではカード幅 `220px` から `280px`、モバイルでは2列または横スクロールで `150px` から `180px` を目安にする。
- 余白は小さくし、カード間 gap はデスクトップ `18px` から `24px`、モバイル `10px` から `14px`。大きな説明文や長いメタ情報はカードに入れない。
- ステータスバッジはサムネイル右上に小さく重ねる。鍵、警告、限定公開などのアイコンは絵文字ではなく Font Awesome などの正規 SVG アイコンを使う。

### 4. イベント絞り込み機能

- **役割**: 過去の特定イベント単位で作品を見返したい時のためのフィルタリング。
- **内部ロジック**: `events` のリストを選択肢として表示し、中間テーブル `video_events` を `JOIN` して指定された `event_id` を持つ動画のみを抽出する。

### 5. 無限スクロール / ペジネーション機能

- **役割**: 作品数が膨大になった際のパフォーマンス低下を防ぐ機能。
- **内部ロジック**: `videos` データ取得時、D1（SQL）のカーソルベース・ページネーション (`WHERE id < cursor LIMIT 20`) を利用し、スクロール下部到達時に追加データをオンデマンドで取得・描画する。

### 6. YouTubeサムネイル表示機能

- **役割**: Cloudflareの容量を圧迫せず、YouTube由来の映像サムネイルを表示する。
- **内部ロジック**: `youtube_video_id`（YouTube 動画ID）を利用し、`https://img.youtube.com/vi/${youtube_video_id}/mqdefault.jpg` を動的に生成して画像要素の `src` に適用する。
  - **優先順位**: YouTube サムネイルを標準とする。外部URL由来の旧サムネイルがある場合も、Cloudflare/R2へ再保存しない。

## 5. 詳細UIロジックとステート管理

### 4-1. 検索・フィルターのステート管理 (URL Sync)

- **同期ロジック**: ユーザーが入力した検索ワードや選択したフィルター、ソート順はすべて `URL Query Parameters` (例: `?q=title&sort=new&status=public`) とリアルタイムに同期させます。
- **メリット**: フィルタリングした状態のURLを他者に共有でき、ブラウザの「戻る・進む」で検索状態を復元できます。

### 4-2. スケルトン表示 (Skeleton UI)

- グリッド内のカード要素がロードされるまで、12枚分程度のスケルトンカードをレンダリングします。
- サイドバーのフィルター項目も、データ取得が必要な要素（イベント一覧など）はスケルトンでプレースホルダーを表示します。

### 4-3. 段階的読み込み (Performance)

- **画像最適化**: Next.jsの `next/image` を活用し、表示域に入る直前に画像を読み込む Lazy Loading と、適切なリサイズを自動適用します。
- **クエリ最適化**: D1（SQL）の検索において、まずは `LIMIT 24` 等で最小限の件数を取得し、ユーザーのアクションに応じて追加取得を行うことで初期読み込み速度を向上させます。

### 4-4. 空状態のハンドリング (Empty State)

- 検索結果が0件の場合、「該当する作品が見つかりませんでした。条件を変えてお試しください」といったメッセージと共に、全てのフィルターをリセットするボタンを表示します。
