## 2026-11-05 D-17-7 notification query URL length parity

- **Finding:** Hono `GET /api/admin-read/ops/notifications` caps `q` at 100 characters; the migrated `AdminNotificationsView` read/API parser caps `q`, but `submitFilters` forwarded arbitrary-length form text into React Router's URL.
