## 2026-11-12 SA-035 async save stale-event audit remediation

- Earlier independent code inspection found a late-result race: an event A template-save response could arrive after the same form was switched to event B, setting B's success/error feedback, invoking B's onSaved callback, redirecting B on stale 401, and keeping B's submit lock held.
