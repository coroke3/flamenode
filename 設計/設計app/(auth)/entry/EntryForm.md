# エントリーフォーム部品設計 (`EntryForm`)

## 1. 役割
イベント参加、スロット確保、利用規約確認、必要項目入力をまとめるフォーム部品。

## 2. 入力
- 参加イベント
- スロット
- 表示名
- アクティブ X ID
- YouTube 動画情報または後日提出フラグ
- イベント固有の `custom_questions`
- 利用規約確認または初回同意

## 3. バリデーション
- `display_name` はスロット公開に使用するため必須。
- アクティブ X ID が未設定の場合は先に設定を促す。
- 初回同意が必要な場合は同意後に進める。規約更新後の再同意は、次回作品投稿、作品編集保存、提出時に必須にする。
- 時間に紐付くスロットは、時間と空き状況（○ / ×）が対応する表から選ぶ。時間に紐付かないスロットは簡易リストから選ぶ。

## 4. 出力
- 下書き、確保済み、提出済み、審査中の状態を明確に返す。
