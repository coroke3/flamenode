# 管理エリアレイアウト設計 (`/(admin)`)

## 1. 役割
管理者およびイベント編集許可者が利用する管理画面の共通レイアウトと権限ガードを定義する。

## 2. 権限
- 管理者はすべての管理機能へアクセスできる。
- イベント編集許可者は、自分に許可されたイベントに関する設定、枠、質問、編集権限制御、担当イベント内作品の内容編集のみ操作できる。
- 協力者は、`event_collaborator_permissions.permission_key` で許可されたイベント管理画面または作品編集画面だけに入れる。管理トップ、ユーザー管理、X ID 承認、全体履歴などの横断管理には入れない。
- 権限外のページでは 403 相当の説明画面を表示し、操作ログは残さない。

## 3. 管理ナビゲーション
- 管理トップ、作品審査、イベント管理、ユーザー管理、履歴、X ID 統合、利用規約管理、インポートを配置する。
- 各画面には現在の操作権限を明示し、イベント編集許可者が管理者と誤認しないようにする。
- 管理画面にもヘッダーとフッターを置く。フッターは環境表示、監査ログ、利用規約管理、問い合わせへの小さな導線に留め、表やフォームの操作密度を下げない。

## 4. 監査
- 管理エリアでの変更は `history_logs` に operator、対象、変更前後、理由を記録する。
