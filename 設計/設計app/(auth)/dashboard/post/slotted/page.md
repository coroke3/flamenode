# 【枠あり】動画投稿・編集フォーム設計 (`/dashboard/post/slotted`)

## 1. 概要
現在進行中のイベント（例：FlameNode 2026 Spring）において、タイムテーブル上の「枠（スロット）」を確保し、エントリー情報および作品情報を提出するページです。
入力負荷を下げるため、**「エントリー時に必須の項目」**と**「動画完成後・振り返り配信までに後から追記する項目」**にフローを明確に分離します。

## 2. データベース連携 (前提)
本フローは、`TECHNICAL_SPEC.md` および本リポジトリの Master Design（内容上は FlameNode 全体設計）で定義された `videos`, `slots`, `video_members` テーブル等のスキーマに準拠します。
特に以下の点に留意します：
- **`owner_discord_user_id`**: 提出時にセッションユーザーの Discord ID を保存。
- **`status`**: 初期提出時は `"pending"` (審査待ち) として保存し、Auto-Public システムによる公開を待機。

## 4. UI/UXのステート管理

### 4-0. 承認待ちX IDでの枠確保

- 枠確保時は `user.active_x_user_id` を `slots.x_user_id` に保存する。
- `approval_status == "pending"` の X ID でも枠確保を許可する。
- 承認待ちの場合は、枠取得の初回のみ「この X ID が却下された場合、受付中イベントの未提出枠は自動解放されます。終了済み・募集終了済みの企画枠は履歴として保持されます」という警告を表示する。連続取得時は同じ警告を繰り返さず、選択操作を妨げない。
- 管理者が X ID を却下した場合、該当 X ID が持つ受付中イベントの未提出 `slots` は `available` に戻り、`discord_user_id`, `x_user_id`, `display_name` をクリアする。終了済み・募集終了済み・提出済みの枠は自動解放しない。
- 受付中イベントで提出済み作品がある場合、作品は `x_reapply_required` として保持し、ユーザーに枠の取り直しを先に促す。その後、X ID 再申請または同一 Discord ユーザーが保有する既存承認済み X ID への付け替えを1つのウィザードで行う。
- 元枠は24時間だけ優先再取得候補として表示する。一般ユーザーには優先再取得中の枠を「選択不可の空き（確保処理中）」として表示し、「この枠は現在、優先再取得手続き中のため選択できません」と説明する。元枠が取れない場合は代替枠を提示し、なければ代替なしとして扱う。連続枠の取り直しでは短縮・延長を許可するが、イベントの最大連続取得数を超えない。
- 再申請を作成したら、その再申請 ID を作品へ紐づけ、作品本文・YouTube ID・メンバー・コメント・チャプターなどの入力済み情報は保持する。再申請中でも作品本文、YouTube URL、合作メンバー、クレジットは編集できる。
- 再申請期限は7日。3日前と24時間前にリマインドし、期限切れ、または枠取り直しをしないままイベント受付が終了した場合は `voided` になる。
- `voided` は物理削除ではなく、公開・一覧・旧形式エクスポート・スコア計算・ランキングから除外される論理無効化。本人向けには通常一覧へ出さず、通知からのみ「不備」と表示する。再登録は別作品扱いになり、旧コメントやチャプターは引き継がない。
- 却下理由は auth 側で表示し、通知は Discord DM と管理画面通知を使う。メール通知は基本的に使わない。

- **メンバー検索のリアルタイム処理**:
  - フォームで文字を入力するたびに、D1 の `x_users.id`, `x_users.x_name`, `x_user_aliases.alias_x_id`, 過去の `video_members.name`, 旧データ由来の `creator/tlink`, `member/memberid` 対応表と照合し、サジェストします。
  - カンマ区切りの複数入力と縦貼り付けデータを受け付け、名前から ID、ID から名前の変換結果を表形式で確認できるようにします。
  - 完全一致しない場合は手動での新規登録（文字入力のみ）を許可します。
- **CSV入力**:
  - メンバー、使用編集ソフト、カスタム質問回答は CSV で貼り付け可能にします。イベント協力者権限の CSV はイベント管理画面で扱います。
  - 各 CSV 入力欄には「CSV作成プロンプトをコピー」ボタンを置き、列名と例を含むプロンプトをコピーできるようにします。
- **自動セーブと一時保存**:
  - 入力中のデータは `localStorage` に保持し、誤ってページを閉じてもエントリー情報を復元できるようにします。
