# FlameNode デザイン統合設計図

## 1. デザイン原則

FlameNode は「映像（フレーム）の結節点（ノード）」を表現する、動画とイベントのためのプラットフォームである。デザインは、作品を主役にしながら、作者・イベント・視聴者の接点が自然に見えることを優先する。

- **作品優先**: サムネイル、プレイヤー、タイトル、作者情報を常に最も見つけやすい位置に置く。
- **黄色アクセント**: 操作可能性、選択中状態、重要な導線、イベント感を鮮やかな黄色で示す。
- **静かな情報密度**: ダッシュボードや管理画面は装飾を抑え、反復操作しやすい密度にする。
- **表示密度**: 公開ページや動画詳細では、過剰な枠や余白で表示数を減らさず、作品カードと関連動画を高密度に並べる。
- **モード両対応**: ライトモードとダークモードを実装し、ユーザー設定または OS 設定に追従できるようにする。

### 旧ページデザインベースの扱い

- トップページと動画詳細ページは、旧 EventArchives ページの「高コントラスト、太い見出し、高密度な作品配置、横スクロール作品棚、右レール関連動画、モバイル上部固定プレイヤー」をデザインベースにする。
- 実装上のサイト名、ロゴ、文言、アクセントカラー、権限導線、イベント機能は FlameNode として再構成する。旧ページ名はデザイン参照元としてのみ扱い、公開 UI の正式表記にはしない。
- 旧ページの黒基調そのものへ必ず準拠する必要はない。ライトモードとダークモードの両方を正式実装するため、色は本設計のテーマトークンを正とし、旧ページからはレイアウト密度、余白の詰め方、作品棚、右レール、操作感を継承する。
- ダークモードでは深い背景色を使って作品サムネイルと文字を強く見せる。ライトモードでは白基調を保ちながら、同じ配置密度、横スクロール、右レール構造を維持する。
- 旧ページの見た目を再現する際も、トップ最上部を大きな文字だけで占有する巨大ヒーローにはしない。旧ページ風の中央タイトル面は、FlameNode では「短い導入帯」として高さを抑え、同一ファーストビュー内に作品棚が入り始めるようにする。
- 追加機能であるアクティブ X ID 切替、イベント参加、スロット、チャプター、コメント、再生リスト、規約再同意、コストガード表示は、旧ページの密度を壊さない小さなチップ、帯、ポップオーバーとして組み込む。

### 旧資料不要の再現基準

この設計書だけでトップページと動画詳細ページを再現できるよう、以下を正とする。旧ページの実物、画像、HTML、CSS がなくても、この基準に従えばよい。

- **全体密度**: 1画面内に「ヘッダー」「導入帯またはプレイヤー」「作品棚または関連レールの先頭」が必ず見える密度にする。装飾のためだけに縦余白を広げない。
- **角丸**: 作品サムネイル、イベントパネル、操作ピルは `8px` 以下を基本にする。丸くするのはクリエイターアイコン、矢印ボタン、再生ボタン、テーマ切替ノブに限定する。
- **影**: 公開ページでは強いドロップシャドウを使わず、背景差、細い境界線、ホバー時の薄いアウトラインで区切る。
- **タイポグラフィ**: 英字ナビは太字、補助日本語は小さくする。本文やカード内では極端な大見出しを使わず、作品タイトルとセクション見出しだけを強くする。
- **テーマ**: ライト/ダークの両方で同じ配置、同じ表示件数、同じスクロール構造にする。ダークだけ特別に情報量が多い、ライトだけカードが大きい、といった差を作らない。
- **アイコン**: 絵文字は使わず、Font Awesome などの正規 SVG アイコンで統一する。アイコンの視覚密度は小さめにし、テキストやサムネイルより目立たせない。
- **追加機能の置き方**: FlameNode 独自の投稿、X ID、スロット、チャプター、再生リスト、規約再同意、コストガードは、大きな説明カードではなく、チップ、細い警告帯、ポップオーバー、右レール内パネル、タブで足す。
- **画面幅基準**: `>= 1440px` は広いデスクトップ、`1000px - 1439px` は通常PC、`700px - 999px` はタブレット、`< 700px` はモバイルとして扱う。動画詳細のウルトラワイドは `20:9` より横長、または幅 `1800px` 以上を目安にする。

## 2. カラートークン

### 共通アクセント

- `--accent-primary`: `#FFD400`
  - FlameNode の主アクセント。鮮やかなイベント感を優先し、主要 CTA、選択中タブ、フォーカスリング、アクティブ X ID、イベント開催中バッジに使う。
- `--accent-primary-strong`: `#FFC400`
  - ホバー、押下、強調線に使う。
- `--accent-primary-soft`: `rgba(255, 212, 0, 0.16)`
  - 選択中背景、通知ハイライト、淡いカード背景に使う。
- `--accent-warning`: `#F59E0B`
  - 締切、注意、再審査警告に使う。

### イベント別アクセント

- `--event-accent`: `events.accent_color` を反映するイベント固有アクセント。
- イベント詳細、イベント参加導線、イベント所属作品、イベント内プレイリストでは `--event-accent` を `--accent-primary` より優先できる。
- `events.accent_color` が未設定の場合は FlameNode の黄色アクセントへフォールバックする。
- イベントごとの色は公式イベントと第三者イベントで同じ扱いにし、外部主催ラベルの代替にはしない。
- イベントアクセントカラーは HEX 入力を許可する。ライト/ダーク背景や白黒文字とのコントラスト不足、背景との同化、警告色との混同が起きる場合は保存前に警告を表示する。
- 複数イベントに属する作品では、`primary_event_id` に紐づくイベントアクセントカラーを優先する。

### ダークモード

- `--bg-base`: `#0B0D10`
- `--bg-surface`: `#141820`
- `--bg-elevated`: `#1C222D`
- `--text-primary`: `#F8FAFC`
- `--text-secondary`: `#CBD5E1`
- `--text-muted`: `#94A3B8`
- `--border-subtle`: `rgba(255, 255, 255, 0.10)`
- `--shadow-soft`: `0 18px 48px rgba(0, 0, 0, 0.36)`

### ライトモード

- `--bg-base`: `#F8FAFC`
- `--bg-surface`: `#FFFFFF`
- `--bg-elevated`: `#F1F5F9`
- `--text-primary`: `#111827`
- `--text-secondary`: `#334155`
- `--text-muted`: `#64748B`
- `--border-subtle`: `rgba(15, 23, 42, 0.12)`
- `--shadow-soft`: `0 14px 36px rgba(15, 23, 42, 0.12)`

## 3. テーマ切替

- 初期値は OS の `prefers-color-scheme` に追従する。
- ユーザーが明示選択した場合は「ライト」「ダーク」「システム」の 3 択で保存する。
- 公開ページ、認証ページ、管理ページのすべてで同じトークン名を使う。
- 動画詳細ページのライトモードは白基調を保つ。プレイヤー枠と独自コントロールは映像視認性のため高コントラストにするが、ページ全体をシアター風の暗い面にはしない。

## 4. 共通レイアウト

### 上部メニューバー

- 左に FlameNode ロゴ、中央または左寄せで主要ナビゲーション、右にログイン状態とアクティブ X ID を置く。
- アクティブ X ID は黄色アクセントの小さなチップで表示する。複数 ID 保有時はクリックで Twitter 風のアカウント一覧ポップオーバーを開き、Discord名、Xでの表示名、X ID、アイコンを並べて選択できるようにする。
- スクロール後も必要に応じて上部に残し、投稿・コメント・いいねの主体が常に分かるようにする。
- トップページ、動画詳細、一覧、イベント、認証ページ、管理画面を含む全ページにヘッダーを置く。管理画面では作業領域を圧迫しない高さにする。

### フッター

- 全ページにフッターを置く。公開ページでは FlameNode の短い説明、利用規約、イベント開催相談、問い合わせ導線を表示する。
- 認証ページでは規約、問い合わせ、トップへ戻る導線を置く。
- 管理画面では現在の環境、規約管理、監査ログ、問い合わせ導線を小さく表示し、作業中の表やフォームを邪魔しない。

### カード

- 作品カードはサムネイル、タイトル、作者アイコン、作者名を必須要素とする。
- カード角丸は 8px 以下を基準とし、過度に丸めない。
- 公開ページのカードやセクションは、表示数を確保するため余白と囲みを最小限にする。
- ホバー時は黄色の細いアウトラインまたは淡いグローで操作可能性を示す。

### ボタン

- 主要 CTA は黄色背景と濃色文字を使う。
- 二次ボタンは透明背景、細い境界線、ホバー時に黄色の薄い背景を使う。
- 危険操作は黄色ではなく赤系または警告色を使い、アクセントの意味を混同しない。

### アイコン・絵文字使用方針

- FlameNode の UI では、ナビゲーション、ボタン、状態表示、警告、SNS 導線、プレイヤー操作、管理画面の操作種別に絵文字を使わない。
- アイコンは Font Awesome を第一候補とし、既存の実装基盤に合わせて Lucide、Material Symbols、Iconify などの正規 SVG アイコンライブラリを採用してよい。いずれの場合も、絵文字や環境依存の記号で代用しない。
- X、YouTube、Discord などのブランド導線は、Font Awesome Brands などライセンス確認済みのブランドアイコン、または各サービスの公式ガイドラインに沿った SVG を使う。
- 実装ではアイコンフォントの一括読み込みより、必要な SVG アイコンだけをコンポーネント化またはサブセット化する方針を優先し、表示速度と Cloudflare 無料枠への影響を抑える。
- すべてのアイコンボタンには `aria-label`、ツールチップ、または隣接テキストを用意し、アイコンだけで意味を判断させない。

## 5. ページ別デザイン方針

### トップページ

- 最上部を大きな文字だけで占有する構成にしない。
- ページ冒頭は、開催中イベント、注目作品、おすすめ導線をコンパクトにまとめた横長の情報帯にする。ブランド説明は短く添えるだけにし、ファーストビュー内で作品カードが見えるようにする。
- 配置順は、コンパクトな開催中/注目エリア、おすすめ作品、クリエイター、最新作品、イベントの順を基本にする。
- セクション内は横スクロールのカードスライダーを基本にする。
- 黄色アクセントは「開催中」「参加する」「おすすめ」などの行動導線に限定し、背景全体を黄色に寄せすぎない。イベント別アクセントカラーがあるイベント関連セクションでは、その色を優先する。
- コンテンツ最大幅は `1400px`、作品カードはデスクトップ `280px`、モバイル `150px` から `220px` を基準にする。
- 横スクロールは全幅に広げ、左右端にフェードを置く。モバイルは2行配置で表示密度を上げる。
- 横スクロールは自動でゆっくり流れる動きを標準にする。PC では左右矢印を常時表示し、ユーザーがホバー、フォーカス、ドラッグ、矢印操作をした場合は自動スクロールを一時停止する。
- `prefers-reduced-motion` が有効な環境では、自動横スクロールと不要なアニメーションを完全に停止する。

#### トップページの旧ページ風再現ポイント

- 背景色はライト/ダークのテーマトークンに従う。ダークモードでは深い背景、ライトモードでは白基調を使い、どちらのモードでもカード背景を多用せず、作品棚が直接並ぶ見え方にする。
- ヘッダーはデスクトップで高さ `64px` 前後、左に2行組み風の FlameNode ロゴ、中央寄りに `TOP / LIST / CREATOR / EVENT` 相当の大きな英字ナビと小さな日本語補助ラベルを並べる。右端にテーマ切替、ログイン状態、アクティブ X ID 切替を小さくまとめる。
- モバイルヘッダーは高さ `42px` 前後に詰め、左にロゴ、右にテーマ切替とハンバーガーメニューを置く。ナビゲーションはドロワー内へ退避し、作品棚の表示領域を削らない。
- 旧ページの中央タイトル面は、高さのあるランディングヒーローではなく、`180px` から `250px` 程度の短い導入帯として扱う。色はライト/ダークのテーマに従い、中央に FlameNode 名、下に1行説明を置くが、直後に「おすすめ」棚が見え始める高さにする。
- 各セクション見出しは中央寄せの太字を基本とし、下に短い線を置く。文字色と線色はテーマトークンに従う。「もっと見る」は同じ行の右側へ小さく配置し、視線を棚から奪わない。
- おすすめ、最新作品は横長サムネイルの作品カードを余白少なめに並べる。カード自体に大きな枠は付けず、サムネイル、2行までのタイトル、丸い作者アイコン、作者名だけで構成する。
- クリエイター棚は丸アイコンを主役にし、丸アイコンと短い名前だけを並べる。アイコン未設定時はテーマに応じたプレースホルダー円を使い、クリック可能な要素としてフォーカスリングを必ず出す。
- イベントセクションは旧ページの大きなイベントパネル風を参考にし、イベントアイコン、イベント名、内部の小型作品グリッドをまとめる。カードは角丸を控えめにし、影より背景差で区切る。
- 左右矢印は旧ページのような半透明の円形ボタンにし、色はテーマトークンに従う。デスクトップでは棚の左右端へ常時表示する。モバイルでは必要時だけ表示し、スワイプ操作を優先する。
- ライトモードでもこの配置を保ち、背景を白、文字を濃色、棚の端フェードを白系に変更する。サムネイル密度、カード幅、見出し位置はダークモードと同じにする。

### 動画詳細

- 旧ページの動画詳細デザインにかなり寄せる。大きな余白や装飾カードではなく、作品情報、プレイヤー、関連動画が高密度に並ぶ構成を優先する。
- ライトモードではページ全体を白基調にし、プレイヤー枠と独自コントロールだけ高コントラストにする。
- 作品ごとの大きな囲みや余白は抑え、関連作品や情報の表示数を確保する。
- 通常PCは、中央寄りにプレイヤーと本文、右に `350px` 前後の関連レールを置く。
- ウルトラワイドでは、左に作品タイトル、投稿者情報、チャプター一覧、中央に動画プレイヤー、右に関連動画と再生リストを置く3カラムにする。左カラムと右カラムは縦スクロール可能にし、中央プレイヤーの視聴面を固定的に保つ。
- `1000px` 未満では1カラムにする。
- 縦長モバイルではプレイヤーを上部固定にし、16:9 比率を維持する。
- 関連動画は横長ミニカードで表示し、サムネイルとタイトルと作者名だけに絞る。標準15件、最大30件を表示できる密度にする。
- 右レールには関連動画の一部として、イベント内上映順、自分のいいね作品、自分のブックマーク/セーブ作品を順番再生できる再生リスト風 UI を置けるようにする。
- 再生リスト風 UI は右レール最上部に置き、その下に「同じ作者」「同じイベント」「おすすめ」などの見出し付き関連動画セクションを続ける。
- 独自プレイヤーのコントロールは黄色を進捗・フォーカス・アクティブ状態に使う。
- マウス停止または領域外移動時はコントロールを即座に非表示にし、映像を遮らない。
- 再生バーには `video_chapters` 由来のチャプターマーカーを小さな点で表示する。点は映像を邪魔しないサイズにしつつ、実操作領域は十分に確保する。
- チャプター点のホバー、タップ長押し、キーボードフォーカスでは、時刻、ラベル、投稿者または種別を小さな吹き出しで見せる。フレーム画像プレビューは必須にせず、YouTube 由来で低コストに取得できる場合だけ任意で扱う。
- フレーム画像プレビューを出せない場合は、時刻、ラベル、周辺コメント数を表示するテキストプレビューを標準代替にする。プレビュー画像を Cloudflare/R2 に保存する設計にはしない。
- 非公開チャプターは本人と管理者だけ半透明の点として表示する。2秒以内に密集する点は1点にまとめ、ホバーまたはタップ時に複数候補をリスト展開する。範囲外チャプターは一覧で「無効（範囲外）」としてグレーアウトし、再生バーには出さない。
- モバイルでもコマ送り操作を必須にし、固定プレイヤーの直下に必要時だけコンパクトな CTA 帯を置く。
- 振り返り上映用データはポップアップで表示し、通常の説明欄と混在させない。
- コメントは YouTube 風のスレッドではなく、ニコニコ動画寄りの時間軸反応として設計する。ただし一覧中心で、強いコメント欄感は出さない。
- チャプターはユーザーが手動設定でき、自分の一覧確認、公開/非公開切替、他ユーザーの公開チャプター閲覧に対応する。コメントは基本的に `video_comments.chapter_id` でチャプターへ紐付ける。
- チャプターとコメントは同じ一覧に混ぜず、「チャプター」「コメント」のタブで切り替える。ニコニコ動画風の流しコメントは将来の任意機能として扱い、既定は OFF にする。
- `x_reapply_required` や YouTube 同期失敗などの対応必須状態は、タイトルと概要の直下に細い警告帯として固定表示する。旧ページ寄せの高密度レイアウトでも埋もれないよう、本文や関連動画の下へ押し流さない。ウルトラワイドの左カラムでは警告帯を sticky にし、モバイル固定プレイヤー下にも同じ導線をコンパクトに出す。
- `x_reapply_required` は一般閲覧者には「調整中」と短く見せ、本人には枠取り直しと X ID 再申請ウィザードを出す。`voided` は一般閲覧者には表示せず、本人には「不備」と表示する。
- 調整中表示は opacity 0.5 程度の薄さにし、テキストで「調整中」バッジを重ねる。ライトモードの警告帯はイベントアクセントカラーより警告色の視認性を優先し、イベントアクセントは枠線などに留める。

#### 動画詳細ページの旧ページ風再現ポイント

- 背景色はライト/ダークのテーマトークンに従う。ダークモードでは深い背景と明るい文字、ライトモードでは白基調と濃色文字で、どちらも YouTube サムネイルとのコントラストを強く出す。本文カードを増やさず、境界線、余白、文字サイズで情報を分ける。
- デスクトップ標準幅では、左から約 `70%` をプレイヤーと作品情報、右 `300px` から `360px` を関連動画レールにする。プレイヤー上部には作者アイコン、作者名、タイトル省略、音量、字幕、設定に相当する小アイコンを重ね、旧ページの「動画上に最小限の情報が乗る」見え方に寄せる。
- プレイヤー中央には半透明の丸い再生/一時停止ボタンを出し、下部には現在時刻、総時間、現在チャプター名、細いシークバー、チャプター点を重ねる。操作していない時はすばやく消え、映像面を広く見せる。
- プレイヤー下部には、共有、あとで見る相当、その他の動画、YouTubeで開く導線を小さなピルまたはアイコンで置ける。これらは旧ページの操作感を参考にするが、FlameNode の再生リスト、ブックマーク、チャプターへ置き換えてよい。
- 右レールは旧ページと同じく縦に詰めた関連動画リストにする。各行は左サムネイル、右タイトルと作者名だけにし、説明文や大きなメタ情報は出さない。サムネイルは `16:9`、行間は `10px` 程度まで詰める。
- タイトルはプレイヤー直下またはウルトラワイド左カラムの上部に大きく置き、下に細い水平線を引く。作者行は丸アイコン、作者名、YouTube/X などの小アイコン、公開日時を横一列に置く。
- イベント前後作品カードは、旧ページの「低いパネル内に小さなサムネイルと前後作品表示がある」見え方を再現する。大きなカード化は避け、イベント名、前後ラベル、サムネイル、タイトルを低い高さに収める。
- メンバー表は旧ページの `No / Name / ID / LINK` 形式を基本にする。交互行はテーマに応じた薄い背景差で分ける。
- モバイルではヘッダー直下に `16:9` の固定プレイヤーを置き、タイトル、作者行、イベント前後カード、メンバー表を縦に続ける。関連動画は本文下へ回すが、必要に応じてプレイヤー直下に数件だけ先出しして連続視聴できるようにする。
- ウルトラワイドでは、旧ページの右レール密度を拡張し、左にタイトル/作者/チャプター/コメント、中央に大きなプレイヤー、右に再生リストと関連動画を固定的に配置する。中央プレイヤーを必要以上に横へ広げすぎず、右レールの一覧性を残す。
- 追加機能のチャプター、時間付きコメント、再生リスト、調整中警告は、旧ページの薄い帯と高密度な情報配置に合わせる。色はテーマトークンに従い、大きなフォームや会話型コメント欄を常設せず、タブ、ポップアップ、折りたたみで密度を守る。

### イベント詳細・スロット表

- 時間ありスロットは、日付・時間・取得者名が見えるスプレッドシート風の表にする。
- 過去日付の枠表は既定で折りたたみ、スクロール量を減らす。
- 優先再取得中の枠は薄いグレーまたは斜線パターンで示し、通常の空き・確定と混同させない。
- スマホでは横スクロール表を維持しつつ、切り替えボタンで日付ごとのカード列表示にも崩せるようにする。
- 取得者名には X ID へのリンクを付与する。ただし承認待ちバッジは一般閲覧者には表示せず、管理者ログイン時だけ補助表示する。

### クリエイター一覧

- アイコンと名前を主役にし、作品数やスコアは補助情報として整列させる。
- 並び替えは「おすすめ」「合計作品数」「名前順」をセグメントコントロールで扱う。
- ライトモードではカード境界を明確にし、ダークモードでは影より境界線と背景差で区切る。

### ダッシュボード

- 操作対象の X ID、作品状態、未対応タスクがすぐ分かる情報設計にする。
- 黄色は現在選択中の ID、保存、提出、次に進む導線に使う。
- 警告、差し戻し、BAN、削除は黄色ではなく専用の警告/危険色を使う。

### 管理画面

- 装飾より情報密度と可読性を優先する。
- テーブル、フィルタ、承認ボタン、履歴差分を一貫した部品で構成する。
- イベント編集許可者と管理者の操作範囲を UI 上で明示する。

## 6. アクセシビリティ

- 黄色アクセントは白背景上で単独の文字色として使わず、濃色テキストや境界線、背景との組み合わせでコントラストを確保する。
- フォーカスリングは黄色を使い、キーボード操作時に明確に見える太さにする。
- 重要な状態は色だけでなく、テキスト、アイコン、ラベルでも示す。
- 動画プレイヤー操作と再生バー上のチャプターマーカーはキーボードでも到達可能にする。
- 自動スクロール、チャプター点のアニメーション、再生リストの自動送り演出は `prefers-reduced-motion` を尊重し、必要に応じて停止する。

## 7. 実装時の受け渡し

- CSS カスタムプロパティまたはテーマトークンで全ページに同じ色名を提供する。
- ライト/ダークの差分はトークン差し替えで吸収し、ページ固有 CSS に色を直書きしない。
- 作品カード、作者チップ、イベントカード、アクティブ X ID チップ、状態バッジは共通部品として扱う。
