# クリエイタープロフィールページ設計 (`/user/[id]`)

## 1. 概要
特定の X ID に紐づくクリエイター情報、SNS、プロフィール、参加作品、ポートフォリオ導線を表示する。

## 2. 表示要素
- アイコン、表示名、`@id`、プロフィール文、YouTube チャンネル、その他 SNS リンクを上部に配置する。
- 活動ジャンルを表示する場合は自由な分類ラベルではなく、プロフィール文や使用編集ソフトの補助情報として扱う。
- 作品一覧はカードグリッドで表示し、公開作品を優先する。

## 3. 作品取得
- `videos.creator_id` が対象 X ID の作品を取得する。
- `video_members.x_user_id` に含まれる合作参加作品も別セクションまたは同一グリッドで扱える。
- 公開プロフィールでは `x_reapply_required`, `voided`, 非公開、手動非表示の作品を表示しない。本人または管理者の場合だけ、必要に応じて別状態として確認できる。
- 作品サムネイルは YouTube サムネイルを生成して表示する。Cloudflare/R2 へ作品サムネイルを保存しない。

## 4. ポートフォリオ
- ポートフォリオは全員必須ではない。ユーザー登録後に本人が有効化した場合のみ `/user/[id]/portfolio` 導線を表示する。
- カスタムページが未公開または未有効の場合は、通常プロフィールと作品一覧のみ表示する。
- 必須機能ではないため、プロフィール/作品一覧より優先度は低めに扱う。
