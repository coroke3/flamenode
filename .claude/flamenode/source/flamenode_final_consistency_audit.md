# FlameNode 修正指示書 取り込み・矛盾精査レポート

## 1. 結論

既存チャットの確定方針、回答済み内容、貼り付けMarkdownの要求、GitHub現行実装を突き合わせた結果、最終統合版の修正指示書は大きな矛盾なく成立する。

ただし、現行GitHub実装には、指示書で明示しておかないと実装後に矛盾が起きやすい箇所がある。  
最終統合版では、それらを「現行GitHub実装を踏まえた注意点」として組み込んだ。

## 3. GitHub現行実装との照合

### 3-1. ID・権限

現行実装では `CurrentUser` に `active_x_user_id` と `is_banned` はあるが、TOS状態がない。  
そのため、TOS再同意を投稿・編集・チャプターコメントに効かせるには、共通ガードでTOS状態を取得できるようにする必要がある。

現行の `canEditVideo` は、`requiredKey` を省略するとイベント権限を持つユーザーが広く編集できる可能性がある。  
最終指示書では、セクション単位でrequiredKeyを明示する方針に修正済み。

### 3-2. スロット

現行実装には `reservation_group_id` があり、連続枠の基礎はある。  
ただし、途中失敗時のロールバック、部分解放、グループ分割、拡張、結合は十分ではない。  
最終指示書ではこれを修正対象として明示済み。

### 3-3. 枠なし投稿

現行実装は `contact_x_id` をフォームから受け、必要ならX IDを作る構造になっている。  
確定方針では、枠なし投稿は連携済みActive X ID必須であるため、この現行仕様は修正対象。  
最終指示書では「自由入力X IDを投稿主体にしない」と明記済み。

### 3-4. いいね / セーブ

現行実装では `videoInteractions.x_user_id` を使っており、X ID主体方針と一致している。  
ただし、未承認X IDでの操作制限、TOS、BAN、CostGuardの共通判定は追加が必要。

### 3-5. チャプター

現行実装では `videoChapters` を使い、Active X IDかつ承認済みを要求しているため方向性は一致。  
ただし、対象動画状態、BAN、TOS、CostGuardのチェックが不足している。  
また、`marker_kind` はMVPでは実質不要のため、固定値扱いにする指示が必要。

### 3-6. 公開API

現行の `/api/videos` は公開作品のみ返しており、基本方針と合っている。  
今後拡張する際は、返却項目のホワイトリスト化、内部情報除外、ページネーション、キャッシュを守る必要がある。

### 3-7. `/admin`

現行の `/admin` はadmin専用であり、今回の「イベント運営者は `/manage`」方針と矛盾しない。  
`/admin` を広げるのではなく、`/manage` を新設するのが正しい。

## 4. 実装後に矛盾が起きやすいポイント

### 4-1. YouTube unlisted と FlameNode unlisted の混同

YouTube側のunlistedはFlameNodeではpublic相当。  
一方、FlameNode内部statusのunlistedは内部限定公開を意味する。  
この2つを同じ変数名で扱うと確実に混乱する。

対策:

- `youtube_privacy_status`
- `visibility_status` または `videos.status`

のように責務を分ける。

### 4-2. 枠なし投稿のX ID

自由入力X IDで即公開すると、未連携X IDでも公開できてしまう。  
連携済みActive X IDだけを使うこと。

### 4-3. イベント運営者の編集範囲

`canEditVideo` をrequiredKeyなしで使うと、細かい編集権限が崩れる。  
セクション別requiredKeyを必須にすること。

### 4-4. 連続枠の一部更新

連続枠を一部だけ解放・追加した後、グループ情報を更新しないと、表示と内部状態がズレる。  
必ず再分割・再結合を行うこと。

### 4-5. deprecated DB項目の再利用

`video_comments` や `marker_kind` を便利だからと再利用すると、コメント廃止方針と矛盾する。  
新規実装では使わないこと。

## 5. 不足確認

最終統合版には、現時点で必須の未決事項は残っていない。  
実装中に詳細判断が必要になった場合も、以下は推奨値として文書化済み。

- 部区切り休憩時間のデフォルト: 30分
- unlisted動画へのチャプターコメント: 許可
- X ID却下時: 自動変更せず要確認
- チャプターコメント: 最小構成
- 枠なし投稿: 連携済みX IDなら即公開
