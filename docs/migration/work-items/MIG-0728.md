## 2026-11-05 U02 template deletion path normalization hardening

- **Finding:** `deleteAdminEventTemplate` correctly URL-encodes normal template IDs, but JavaScript's `encodeURIComponent(".")` and `encodeURIComponent("..")` return raw dot segments. The browser normalizes `/api/admin/event-templates/.` to `/api/admin/event-templates/` and `/api/admin/event-templates/..` to `/api/admin/`. Thus a malformed API-provided template ID could send a privileged DELETE request to an unintended path. The list schema permits arbitrary strings; the client must reject unsafe IDs before networking.
- **Fix:** fail closed on exact `.` and `..` ID values, preserving the existing no-empty/no-surrounding-whitespace rule and encoded route for normal IDs. Existing `try/catch` still prevents malformed UTF-16 surrogates from reaching fetch. No backend, D1, auth policy, schema, router mount, deploy or Cloudflare resources changed.
- **Evidence:** source `83aa06db8473b4a51cd88b4be9d97f1dcb377f18`; JSDOM/Node regression `970ff6998e7324ee8b0ee6bda64ffb76c990762e` asserts real URL dot segment normalization, rejects `.`/`..`/empty/whitespace/isolated UTF-16 surrogate with **zero DELETE requests**, and preserves valid template deletion; matrix `c0fc201db700982625083afc0eba0790f8c5b76e`.

## 2026-11-05 U02 AdminEvents IME submit contract parity

- **Finding:** CURRENT `AutoSubmitSelect` skips auto-navigation while the parent GET form carries `data-fn-ime-composing`, and `ImeSafeGetForm` suppresses commit-Enter submissions. The migrated Ops `AdminEvents` used bare `requestSubmit()` in the public-filter/sort selectors and unconditional `change(form)` in submit. While a Japanese IME is converting text in `q`, a selector change or commit submit could push a partially converted search to the SPA router.
- **Fix:** `AdminEvents` uses the shared `IME_COMPOSING_FORM_ATTR`/`isImeComposingForm` marker, sets it for actual composition sessions and Windows Process/229 implicit key cases, clears after the commit event tick, and blocks both auto-select and manual form navigation until the session ends. The existing `FormData` normalization, URL parameters and reads remain unchanged; normal subsequent search works. No server routes, privileges, D1, schema or production deployment modified.
- **Source:** `ce6f4ade4e7a37fc19bf6eb00a4cde6bf7a3e624`; **JSDOM regression:** `e8b4dccaaf4a61e0bb3da457bb82e4ba6e70e8c6` verifies compositionstart, selector change, ordinary submit, compositionend same tick, later valid search using Japanese q. **Matrix:** `a0f7c10fed510a981610a857d39aa7b2b212459c`.
