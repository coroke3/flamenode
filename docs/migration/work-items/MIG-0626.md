## Decisions
- Decision (agent, 2026-10-23): mount at `/api/admin-read/*`. The #331 head (`apps/api/src/routes/admin/index.ts`) guards only non-GET/HEAD/OPTIONS under `/api/admin` and states that GET reads "mount their own read guard", so a separate prefix avoids colliding with the mutation router. MIG-0625 should mount in the same `adminReadRoutes` (`routes/adminRead/index.ts`) so the guard is shared.
- Decision (agent): guard = `sessionMiddleware()` -> `requireAuth()` (401 anonymous, 403 banned) -> `role === "admin"` else 403. CURRENT layout redirects (no user -> /entry, non-admin -> /dashboard) and several pages notFound() non-admins; all become 401/403.
- Decision (agent): DTOs carry only the columns the page renders (drizzle `.select()` rows are projected); the audit list/detail return audit rows as stored (payloads were redacted when written), nothing added.
- Decision (agent): ZERO_1102 S2 consolidation. Every endpoint is <= 3 D1 statements incl. the session lookup (asserted by the tests): rules = UNION ALL list+published, then a separate re-accept count (its failure is swallowed as CURRENT); audit detail merges prev/next into one statement; notifications joins the recipient lookup and folds the unhealthy-lease count into the counts statement; audit restore joins audit_logs.
- Decision (agent): 64 KiB response budget. Audit list, notifications and cost-guard history keep rows (newest first, at least one) up to 48 KiB and set `truncated: true`; CURRENT renders every row. Audit detail returns one row whole (the audit payload cap is a setting, default 120 KB) and can exceed 64 KiB.

## Failure parity
- D1 failure on the primary read -> 503 `{error:"unavailable"}` (CURRENT throws to the error page). Exceptions that mirror CURRENT's try/catch: rules re-accept count -> 0 (200); cost-guard settings/history -> defaults (200); notifications list/counts -> 200 with `error:"query_failed"` and empty data (fixed code, CURRENT prints `String(cause)`).
- Not found (announcement, rule, event group, audit id) -> 404 `{error:"not_found"}` = CURRENT notFound().
