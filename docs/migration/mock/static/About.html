使う人

見る人へ
新着、ピックアップ、作者、イベントから作品を探せます。作品ページでは、メンバー、チャプター、関連作品も合わせて見られます。
投稿する人へ
YouTube 作品を、表示名、アイコン、X ID、合作メンバー、イベント所属と一緒に登録できます。イベント枠に紐づく提出も同じ流れで扱います。
運営する人へ
募集枠、提出状況、公開作品、スタッフ権限、通知、変更履歴をまとめて扱い、開催後のアーカイブにもつなげます。

3つの原則

作品を主役にする説明より先に、サムネイル、タイトル、作者、再生導線が見える密度を保ちます。
名義を分けて守るDiscord はログインだけに使い、作品に出る名義は X ID です。2つを混ぜずに扱います。
イベントを記録にする募集ページだけで終わらせず、投稿枠、公開作品、履歴まで同じイベントに残します。
