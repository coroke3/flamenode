## Rules (`apps/site/public/_redirects`)
```
/groups /event 307
/groups/ /event 307
/groups/:slug /event#event-group-:slug 307
/groups/:slug/ /event#event-group-:slug 307
```

The trailing-slash forms exist because the gateway asks Assets for the directory form of a fixed page. The MIG-0502 integration `eventRedirects` appends its generated block to the built file and keeps these lines (tested).

## Findings (local `wrangler dev`, workerd, 2026-10-23; `scripts/migration-groups-redirects.wrangler-smoke.mjs`)
| Request | CURRENT (Next) | Static Assets alone | Behind the gateway (MIG-0619 edge policy, on main) |
| --- | --- | --- | --- |
| `/groups` | 307 `/event` | 307 `/event` (match) | 307 `/event` (match) |
| `/groups/` | 308 `/groups`, then 307 | 307 `/event` | 307 `/event` (match) |
| `/groups/spring` | 307 `/event#event-group-spring` | 307 `/event#event-group-spring` (match, fragment kept) | 307 `/event#event-group-spring` (match) |
| `/groups/a%20b` (T03) | 307 `/event#event-group-a b` (raw decoded slug) | 307 `/event#event-group-a%20b` | 307 `/event#event-group-a%20b` |
| `/groups?x=1` (T04) | 307 `/event` (query dropped) | 307 `/event?x=1` (query kept, mismatch) | 307 `/event` (query dropped, match) |
| `/groups/spring?x=1` | 307 `/event#event-group-spring` | 307 `/event?x=1#event-group-spring` | 307 `/event#event-group-spring` (match) |
| `/groups/a/b` | 404 | 404 | falls through to the normal 404 handling |

- T03: `…a%20b` and `…a b` are the same URL after parsing; the browser resolves the hash to the element id `event-group-a b` (the `/event` Island scrolls with `decodeURIComponent`). Judged equivalent; recorded, not "identical bytes".
- STOP 1 (T04): Workers Static Assets always appends the request query to a `_redirects` destination (`/event?` does not strip it, probed). `/groups?x=1` therefore lands on `/event?x=1`; CURRENT drops it. The `/event` Island ignores unknown keys, but `/groups?q=foo` would apply the filter. A rule cannot express "drop the query": only the gateway Worker can (it builds the Assets request from the path alone).
- Gateway: since MIG-0619 the gateway answers `/groups` and `/groups/{slug}` itself (307, query dropped, same table as `edgePolicy.test.mjs`), so with the gateway in front all rows match CURRENT including the query. The earlier PoC finding (200 / 503) no longer applies; the smoke script now asserts the gateway section too.
- STOP 1 remains only for an Assets-only deployment (no gateway in front): a `_redirects` rule cannot drop the query. With the gateway in front (the plan) everything matches.
