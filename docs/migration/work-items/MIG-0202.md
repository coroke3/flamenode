## Scope
Shared UI primitives in packages/ui extracted from mock design system (Recipe R-UI, Runtime N).
- Button: variant, size, loading (aria-busy), disabled, type="button" defaults.
- Badge (Status): icon + status label matching mock Status specification.
- Dialog (Modal): accessible modal with role="dialog", aria-modal, focus moves in on open and back to the opener on close, Esc close (not when contained, as in the mock), bodyScrollLock. No focus trap (the mock has none).
