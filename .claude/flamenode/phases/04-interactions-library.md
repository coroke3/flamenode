# Phase 4: いいね・セーブ・ライブラリ・再生リスト

## 目的

いいね、セーブ、ライブラリ、再生リストをDiscord ID主体ではなくX ID主体に統一し、Active X ID切替と完全に連動させる。

## 推奨モデル

- 実装: Sonnet
- 調査のみ: Haiku可
- ID主体が曖昧な場合: Opus

## 対応要求ID

A-5、G-1〜G-7、I-1、I-3、J-14、N-5、O-2

## 必須仕様

- いいね・セーブ・ライブラリ・再生リストはX ID単位で管理する。
- Discord ID主体にしない。
- Active X ID切替で以下が変わる。
  - いいね
  - セーブ
  - ライブラリ
  - 全て再生プレイリスト
- UIだけでなく取得API、クエリ、playlist生成も確認する。
- 全て再生時に出るべき再生リスト/お気に入りリストが出ない不具合を修正する。
- いいね/セーブの保存先IDを開発環境で確認できるようにする。
- 未承認X IDでの操作制限、TOS、BAN、CostGuardの共通判定を追加する。
