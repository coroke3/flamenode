### Important acceptance interpretation

The Phase 6 card says “途中失敗の全件 rollback”, whereas CURRENT intentionally commits **one atomic stage per request** and explicitly reports `committed_progress_pending` if the later R2 progress CAS fails. “Whole import rollback” across previously committed HTTP requests is **not** CURRENT behavior. For U02, test per-step atomic rollback plus cross-store recovery; do not invent global transaction semantics. This difference must be accepted by a qualified reviewer/Lead before final parity sign-off.
