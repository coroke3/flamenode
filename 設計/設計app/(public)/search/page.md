# 検索ページ設計 (`/search`)

## 1. 概要
作品、イベント、クリエイターを横断検索する公開ページ。

## 2. 検索対象
- 作品: タイトル、作者名、楽曲、クレジット、説明文、使用編集ソフト。
- クリエイター: X ID、表示名、プロフィール文。
- イベント: タイトル、概要、開催期間。
- 汎用分類ラベルによる検索・絞り込み UI は実装しない。使用編集ソフトは辞書と別名候補で表記ゆれを吸収したうえで検索対象にする。

## 3. クエリ
- URL クエリ `?q=` を検索語として受け取る。
- 結果種別はタブで「すべて」「作品」「クリエイター」「イベント」に分ける。
- D1 の制約を考慮し、初期実装は `LIKE` 検索、将来的には KV インデックスを併用する。

## 4. 表示
- 作品は動画カード、クリエイターは小型プロフィールカード、イベントはイベントカードで表示する。
- 公開検索の作品結果には `x_reapply_required`, `voided`, 非公開、手動非表示の作品を含めない。`x_reapply_required` はイベント詳細ページ側で「調整中」として扱う。
- 該当なしの場合は条件変更とトップ/一覧への導線を提示する。
