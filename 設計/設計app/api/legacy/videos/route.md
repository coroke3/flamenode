# 旧互換動画一覧API設計 (`/api/legacy/videos`)

## 1. 役割
OBS や外部表示システムが FlameNode の公開動画一覧を取得するための旧互換 API。

## 2. 認証
- 旧互換 API 用トークンまたは署名ヘッダーで認可する。
- 未認可リクエストには 401 を返す。

## 3. 出力
- `success`
- `data`: 旧アーカイブ互換の動画配列
- 各動画にはタイトル、作者名、YouTube ID、YouTubeサムネイル URL、イベント ID、公開状態、上映時刻を含める。
- 作品サムネイルは Cloudflare/R2 に保存せず、YouTube ID から生成した URL を返す。

## 4. フィルタ
- 既定では公開可能な作品のみ返す。
- `x_reapply_required` は通常出力から除外する。公開イベントページでは「調整中」として薄く表示できるが、旧上映ツールや連続再生には戻さない。管理者・運営向け詳細CSVでは状態フラグ付きで出力できる。
- `voided` は通常出力、管理者向け詳細出力、スコア・上映順の対象から除外する。監査・統計専用の別レポートにのみ出力し、通常の旧互換レスポンスへ混ぜない。
- 管理用途の限定公開出力は別トークンまたは別スコープで制御する。

## 5. 監査
- 外部 API アクセス回数、失敗回数、呼び出し元を記録する。
