# アップロードAPI設計 (`/api/upload`)

## 1. 役割
アイコン画像のアップロード受付と R2 保存先発行を行う。作品サムネイル、イベント用ビジュアル、動画本体は Cloudflare/R2 にアップロードしない。

## 2. 認証
- ログイン済みユーザーのみ利用可能。
- Origin チェックにより CSRF を防止する。

## 3. 入力
- 直接ファイルアップロード、または署名付きアップロード URL 取得リクエストを受け付ける。
- 許可 MIME は `image/jpeg`, `image/png`, `image/webp`。
- 元ファイルの最大サイズは1ファイル8MB。
- 保存前にクライアント側で `250x250px` の WebP へ圧縮する。サーバー側でもサイズ、MIME、Magic Number を検証する。
- 拡張子だけでなく Magic Number を検証する。

## 4. 出力
- 成功時は `public_url` または署名付きアップロード URL を返す。
- 保存先キーは `icons/{user_id}/...` のようにユーザー単位で分離する。
- 作品カードや動画詳細のサムネイルは YouTube サムネイル URL を使うため、この API の対象外とする。
- R2 のアイコン配信には `Cache-Control: public, max-age=86400, stale-while-revalidate=604800` を付与する。
- 旧アイコンは月次ワーカーで最大200KB程度の WebP へ圧縮・上書きできる。8MB上限は新規アップロード時の元ファイル制限として扱う。
- `read_only` 以上では新規アップロードを停止し、管理者の30分一時許可がある場合だけ許可する。

## 5. エラー・監査
- 未認証、Origin 不正、ファイル種別不正、サイズ超過、内容不一致を明確に返す。
- アップロード成功と失敗は監査対象にする。
