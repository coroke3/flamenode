# ルートレイアウト設計 (`/`)

## 1. 役割
FlameNode 全体の HTML メタデータ、共通テーマ、上位レイアウト境界を定義する。FlameNode は「映像（フレーム）の結節点（ノード）」を掲げる、YouTube 埋め込みを利用した動画プラットフォームであり、イベント参加手続きと第三者イベント開催を扱う。

## 2. 共通メタデータ
- サイト名は `FlameNode` とする。
- メタディスクリプションは「映像（フレーム）の結節点（ノード）。YouTube埋め込みを利用した動画プラットフォーム。イベント参加手続きと第三者イベント開催に対応。」を基準にする。
- ページタイトルは `%s | FlameNode` の形式を基本とし、トップページのみ `FlameNode` を単独表示する。

## 3. 共通UI
- すべてのページは共通の背景、フォント、アクセントカラー、レスポンシブ余白を共有する。
- すべてのページはヘッダーとフッターを持つ。公開エリアは通常フッター、認証エリアは操作導線付きフッター、管理エリアは作業を邪魔しない簡易フッターにする。
- 認証済みユーザーには、上部メニューバーで現在のアクティブ X ID を常時表示する。
- アクティブ X ID 切替は設定ページだけでなく、投稿、いいね、ブックマーク、コメント、時間付きコメントの既定主体を変えるグローバル操作として扱う。
- 切替 UI はクリック即変更ではなく、Twitter 風の一覧ポップオーバーを開いて選ぶ。各候補には Discord名、Xでの表示名、X ID、アイコンを表示する。
- UI 上のアイコン表現に絵文字は使わない。ナビゲーション、ボタン、状態表示、警告、SNS導線、プレイヤー操作、管理画面の操作種別は Font Awesome を第一候補とし、既存基盤に応じて Lucide、Material Symbols、Iconify などの正規 SVG アイコンライブラリで表現する。

## 4. 設計上の注意
- 旧実装から引き継ぐレイアウト意図は各ページの設計図に整理し、後続の実装時に迷わない粒度で残す。
