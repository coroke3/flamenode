# 作品編集ページ設計 (`/dashboard/edit/[id]`)

## 1. 概要
既に登録・提出済みの動画作品の情報を修正するための専用ページです。

## 2. デザイン方針

- **コンセプト**: "Refinement & Polish" (ブラッシュアップを支える)
- **レイアウト**:
    - **左側**: タイトル、クレジット、メンバー追加等を行うメイン入力フォームエリア（YouTube StudioやDiscordのサーバー設定のリファレンス）。
    - **右側**: 編集内容がリアルタイムに反映されるカードプレビューと、現在の審査ステータスを表示するサイドパネル。
- **視覚演出**: 編集可能なフィールドには、フォーカス時に Primary カラーのグロー効果を与え、どこを編集しているかを明確にします。未変更箇所と変更箇所のコントラストを調整し、保存前の最終確認を容易にします。
- **ライト/ダークモード**: `FlameNode-Design-System.md` のトークンに従い、背景色と入力フィールドのコントラストを最適化して、長時間の編集作業でも目が疲れにくい設計を行います。
- **体験**: 重大な変更（YouTube IDの変更など）に対しては、サイドプロンプトやモーダルで即座にリスク（再審査の必要性など）を提示し、ユーザーの意図しないミスを防ぎます。


## 3. 目次・機能一覧

1. **既存データ読込・復元機能**: D1 からの現在値取得
2. **限定項目編集機能**: `music`, `credit`, `closing_comment`, `video_members`, `used_software` など許可済み項目のみ編集可
3. **ステータス表示・警告機能**: 承認状況に応じた編集制限の表示
4. **差分更新（Patch）機能**: 変更箇所のみの D1 更新

## 4. 各機能の詳細解説

### 1. 既存データ読込・復元機能

*   **役割:** 現在の登録内容をフォームの初期値としてセットする。
*   **内部ロジック:** 
    *   URLの `[id]` パラメータをキーに `videos` レコードを取得。
    *   **権限チェック:** `creator_id` が `active_x_user_id` と一致するか、管理者であるか、当該イベントのイベント編集許可者であるか、または対象作品が属するイベントの `event_collaborator_permissions` で協力者権限を付与されている場合に編集を許可。不一致の場合はリダイレクト。

### 2. 動的項目編集制限機能
*   **役割:** 管理者が設定した権限に基づき、編集可能なフォーム項目を制限する。
*   **内部ロジック:**
    1.  **判定順序**:
        - **新規/枠あり特例**: 作品が `slots` に紐づいている（未公開）場合、原則として全項目を編集可能にする（`system_settings.upcoming_editable_fields` を参照）。
        - **X ID再申請中**: `status == "x_reapply_required"` の作品は、作品本文、YouTube URL、合作メンバー、クレジットを編集可能にする。タイトルと概要の下に、枠取り直しを先に行うウィザード導線を固定表示する。
        - **イベント優先**: `primary_event_id` に紐づく `events.editable_fields` (JSON) が設定されている場合、それを適用。
        - **全体デフォルト**: 上記がない場合、`system_settings.default_editable_fields` を適用。
    2.  **UI制御**:
        - 許可されていない項目は `disabled` 状態にし、鍵アイコンを表示。
        - 「この項目は現在、管理者によって編集が制限されています」等のツールチップを表示。

### 2-2. 編集権限設定の操作権限
*   **役割:** 作品を編集する権限と、どの項目を編集可能にするかを設定する権限を分離する。
*   **内部ロジック:**
    *   通常ユーザーは、許可済みフィールドの範囲内でのみ作品情報を編集できる。
    *   協力者は、対象作品が属するイベントの `event_collaborator_permissions.permission_key` で許可された項目のみ編集できる。合作メンバーとして掲載されているだけでは編集権限を持たない。
    *   `events.editable_fields` や全体デフォルトの編集可否を変更できるのは、管理者または当該イベントに対して許可されたイベント編集許可者のみ。
    *   過去作品の編集権限と削除権限もイベント単位で設定できる。削除権限は通常の項目編集より強い操作として、管理者が明示的に許可した場合のみ有効にする。
    *   権限設定 UI は一般ユーザーには表示しない。許可者には現在のイベント、対象フィールド、影響範囲、監査ログ記録の説明を表示する。
    *   設定変更時は `history_logs` に、変更者、対象イベント、変更前後、理由を保存する。

### 2-3. イベント協力者権限の適用
*   **役割:** 管理者またはイベント編集許可者がイベント管理画面で付与した協力者権限を、イベント内作品の編集画面に反映する。
*   **UI:** 協力者として入った場合、許可された権限キーに対応する項目だけを活性化する。例として `videos.music_credit` なら楽曲名・クレジット・楽曲URLのみ、`videos.review_data` なら振り返り上映用データのみ編集できる。
*   **入力補助:** 協力者名または X ID の管理はイベント管理画面で行う。作品編集画面では、現在の協力者権限と対象イベント名を表示する。
*   **保存:** 協力者による変更は通常の作品差分として保存し、`history_logs` には協力者本人、対象イベント、使用した `permission_key` を記録する。
*   **制限:** 協力者に付与された権限は、イベント編集可能フィールドや全体設定で許可されている範囲を超えない。本人承認フローは不要。

### 3. ステータス表示・警告機能

*   **役割:** 編集によって審査に影響が出る可能性をユーザーに伝える。
*   **内部ロジック:** 
    *   `status == "public"`（承認済相当）の作品を大幅に修正（YouTube IDの変更等）する場合、「再審査が必要になる可能性があります」という警告を出す。
    *   `status == "unlisted"` かつ `last_error` が存在する場合（差し戻し相当）は、運営からのフィードバックを最上部に表示。
    *   `status == "voided"` の作品は通常編集不可とし、本人には「不備」と表示する。管理者が復旧または確認する場合は管理画面側の監査表示から扱う。

### 4. 差分更新（Patch）機能

*   **役割:** 効率的なデータ更新。
*   **内部ロジック:** 
    *   `updated_at` に現在時刻をセット。
    *   変更されたフィールドのみを `videos` レコードへ更新する。

## 5. 詳細UIロジックとステート管理

### 4-1. プレビュー機能
*   編集後のタイトル、作者名、YouTube サムネイルが、リストページでどのように見えるかをリアルタイムにシミュレート表示します。
*   作品サムネイルはアップロードせず、YouTube サムネイルを利用します。

### 4-1-1. 利用規約再同意
*   最新の利用規約へ未同意の場合、保存前に再同意画面を表示します。
*   再同意が完了するまで保存ボタンは無効化します。

### 4-2. 編集履歴の保持
*   重大な変更（メンバーの削除など）を行う際、`history_logs` へ変更前のスナップショットを自動保存し、運営が後から経緯を追えるようにします。
