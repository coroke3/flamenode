## 2026-11-05 U02 template deletion path normalization hardening

- **Finding:** `deleteAdminEventTemplate` correctly URL-encodes normal template IDs, but JavaScript's `encodeURIComponent(".")` and `encodeURIComponent("..")` return raw dot segments. The browser normalizes `/api/admin/event-templates/.` to `/api/admin/event-templates/` and `/api/admin/event-templates/..` to `/api/admin/`. Thus a malformed API-provided template ID could send a privileged DELETE request to an unintended path. The list schema permits arbitrary strings; the client must reject unsafe IDs before networking.
- **Fix:** fail closed on exact `.` and `..` ID values, preserving the existing no-empty/no-surrounding-whitespace rule and encoded route for normal IDs. Existing `try/catch` still prevents malformed UTF-16 surrogates from reaching fetch. No backend, D1, auth policy, schema, router mount, deploy or Cloudflare resources changed.
- **Evidence:** source `83aa06db8473b4a51cd88b4be9d97f1dcb377f18`; JSDOM/Node regression `970ff6998e7324ee8b0ee6bda64ffb76c990762e` asserts real URL dot segment normalization, rejects `.`/`..`/empty/whitespace/isolated UTF-16 surrogate with **zero DELETE requests**, and preserves valid template deletion; matrix `c0fc201db700982625083afc0eba0790f8c5b76e`.
