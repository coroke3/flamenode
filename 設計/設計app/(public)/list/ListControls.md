# 作品一覧コントロール部品設計 (`ListControls`)

## 1. 役割
作品一覧ページの検索、ステータス、イベント、並び替えを制御する UI 部品。

## 2. 入力
- フリーワード
- 公開状態
- イベント
- 並び順
- 使用編集ソフト

汎用分類ラベルによる絞り込みは設計しない。使用編集ソフトだけは辞書と別名候補に基づくチップ型フィルタとして扱う。

## 3. URL同期
- すべての状態を URL Query Parameters に同期する。
- ブラウザ戻る/進む、共有 URL、再読み込みで状態を復元する。

## 4. 表示制御
- 一般ユーザーには公開作品以外のステータス選択を非表示または無効化する。
- 管理者と作品所有者には必要な範囲で補助ステータスを表示する。
