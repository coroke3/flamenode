# 動画審査部品設計 (`VideoReview`)

## 1. 役割
管理者またはイベント編集許可者が、提出された作品の状態確認、差し戻し、公開許可、非公開化を行うための審査部品。

## 2. 表示
- 作品タイトル、作者、アクティブな提出者、YouTube ID、YouTubeサムネイル、現在ステータス。
- 必須項目の不足、YouTube 検証状態、X ID 承認状態を一覧表示する。
- `x_reapply_required` は通常の審査対象と同じ列に表示し、名義、再申請期限、枠取り直し状態、通知状態を併記する。
- `voided` は通常審査列から外し、管理者がフィルタで明示した場合だけ表示する。本人向け文言は「不備」とする。

## 3. 操作
- 承認、差し戻し、限定公開、非公開、手動非表示を切り替える。
- 差し戻し時は理由を必須入力にする。

## 4. 監査
- 審査操作はすべて `history_logs` に保存する。
