# クリエイター一覧ページ設計 (`/user`)

## 1. 概要
FlameNode に参加しているクリエイターを一覧し、作品やプロフィールへの入口を提供するページ。

## 2. レイアウト
- 上部に `CREATOR / クリエイター一覧` のタイトルを表示する。
- その下に並び替えコントロールを置き、カードグリッドでクリエイターを表示する。
- 各カードはアイコン、表示名、X ID、作品数の概要をまとめる。旧資料がなくても再現できるよう、丸アイコンを主役にした高密度グリッドとして設計する。
- デスクトップではカード幅 `160px` から `200px`、アイコン直径 `72px` から `88px`、名前1行、X ID 1行、作品数は小さな補助表示にする。
- モバイルでは2列から3列を基本にし、アイコン直径 `56px` から `64px`、名前は1行省略にする。
- カードの囲みは控えめにし、ライト/ダークのテーマトークンで背景差と細い境界線を出す。絵文字は使わず、作品数や外部リンクの補助アイコンは Font Awesome などの正規 SVG アイコンを使う。

## 3. 並び替え
- デフォルトは `creator_score` 降順。
- 「合計作品数順」は個人作品数と合作参加作品数の合計で降順に並べる。
- 「名前順」は表示名の五十音または locale compare で昇順に並べる。

## 4. 集計
- 個人作品数は `videos.creator_id` が該当 X ID の作品数。
- 合作参加作品数は `video_members.x_user_id` が該当 X ID の作品数。
- 合計作品数は個人作品と合作参加の重複を除外して算出する。

## 5. 表示制御
- 一般ユーザーには公開作品に関わるクリエイターを中心に表示する。
- 管理者は承認待ちや非公開状態の関連情報を補助表示できる。
