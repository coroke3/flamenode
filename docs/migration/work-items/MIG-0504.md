A wrong user inside a profile object, a hash / generation / JSON problem fails the build.
- Non-public videos: CURRENT `normalizePublicVideoCard` keeps only `status = public` rows in every section and page (T02 asserts private/voided titles are absent from HTML).
- The producer of these objects does not exist yet (MIG-0401/0410 follow-up), as for the about-stats snapshot.

## Parity gaps (task is not DONE)
1. Mixed-case or `@`-prefixed X ID URLs: CURRENT lower-cases and serves; the static site has lower-case paths only. Redirect/case folding belongs to the gateway (MIG-0404/0405). CURRENT has no old-ID redirect either; T03 "旧 X ID → 新ID" depends on the D-03 alias decision and is not implemented here.
2. The X icon map (`loadPublicXIconMapOptional`) used by the portfolio is not an input; with no entry in the map CURRENT shows the stored icon, which is what is rendered. A map entry that overrides an icon is not applied.
3. Up to 15+15 pages of 8 cards are embedded in each profile Island's props to serve `?worksPage=`. Measure the HTML size on real data; if large, move pages to per-page JSON like the index.
4. `/user/index.json` holds the whole index (about 120 bytes per creator) and is fetched only when a query is present. `/user/index.json` is a static asset that must win over the gateway's `/user/:id` handling (route map / gateway check pending).
5. Browser check at 390px / 1440px is not done in this run (no browser). Structure and classes follow `static/Creators.html` and `static/Portfolio.html`. Hydration of the two Islands is exercised in jsdom only.
6. `og:image` for a Google Drive icon is `/api/google-drive-image/<id>` and thumbnails are `/api/youtube-thumbnail/...` as in CURRENT; those API routes must exist on the Astro Worker at cutover.
7. /user/[id] queue regeneration is excluded; Island-page queue parity (Astro serializer port or AstroContainer in the consumer Worker) is an MIG-0411 follow-up (lead). After Phase 5 the consumer's production role for this kind is the unpublish DELETE + tracker close; a gateway miss stays 503 until the build (MIG-0509) provides the HTML. The renderer's render branch is test-only live code until the Island-parity follow-up (lead decides: restore parity, or delete the renderer and make it injectable). See OPEN_DECISIONS.md D-11.
