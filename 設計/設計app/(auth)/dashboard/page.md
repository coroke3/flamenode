# ダッシュボード設計 (`/dashboard`)

## 1. 概要
クリエイター（参加者）がログインした際に最初に表示される管理画面トップページです。自身の登録情報の確認や、投稿作品の状態（審査中・公開等）、開催中のイベント参加枠の管理を行うための起点となります。

## 2. デザイン方針

- **コンセプト**: "Creator's Control Center" (制作活動の司令塔)
- **レイアウト**:
    - **全体サイドバー**: 運営ホーム、作品管理、設定、ログアウトを配置する共通ナビゲーション。
    - **プライマリ・ガイド**: 画面最上部に、今最も行うべきアクション（例：「エントリーする」「動画を提出する」）を大型バナー/カードで強調表示。
    - **統計・ステータスエリア**: 再生数、いいね数、投稿作品数、企画に投稿した作品数、自分で登録した作品数をタイル状に並列表示。
- **視覚演出**: `FlameNode-Design-System.md` の `--bg-surface` と控えめなガラス質感を付与。アクションが必要なタイルは黄色の `--accent-primary` の微かなグローを持たせます。
- **体験**: 未提出のスロットがある場合、カウントダウンタイマーをダッシュボード上で強調し、締切への意識を高めます。


## 3. 目次・機能一覧
1. **アイデンティティ統合表示**: Discord プロフィールと連携済み全 X ID のステータス
2. **アクティブ・スロット管理 (メイン)**: 予約済み枠のステータスと提出・編集アクション
3. **マイ・ギャラリー**: X ID ごとの投稿作品一覧と審査ステータス
4. **エンゲージメント・スタッツ**: 再生数、いいね数、投稿作品数等の簡易アナウンス
5. **運営お知らせ**: 締切リマインドとイベント導線

## 4. 各機能の詳細解説

### 1. アイデンティティ統合表示
*   **役割:** 自身がどのアカウントとしてシステムに認識されているかを明確にする。
*   **内容:**
    - **Discord**: アイコン、ユーザー名、ID。
    - **連携 X ID**: 紐付けられている全ての X ID (`x_users`) をリスト表示。
    - **ステータス**: 未連携の X ID がある場合や、承認待ちの X ID がある場合に警告バッジを表示。

### 2. アクティブ・スロット管理 (メイン・ヒーローエリア)
*   **役割:** ユーザーが今「何をすべきか」を最優先で提示する。
*   **デザイン:** 画面中央上部にカード形式で配置。
*   **振る舞い:**
    - **予約中 (`reserved`)**: イベント名、予約日時を大きく表示。「動画を提出してエントリーを完了する」ボタンを強調（`/dashboard/post/slotted` への導線）。
    - **提出済 (`submitted`)**: 「提出完了！審査をお待ちください」のメッセージと、内容の確認・修正ボタンを表示。
    - **X ID再申請中 (`x_reapply_required`)**: 作品名義を主表示にし、却下されたID文字列を主表示にしない。タイトルと概要の下に「枠の取り直しが必要です」という固定導線を置き、枠取り直しを先に案内する。続けて X ID 再申請または既存承認済み X ID への付け替えを1つのウィザードで行う。
    - **再申請期限**: `x_reapply_required` になってから7日以内に対応する。期限切れの3日前と24時間前に Discord DM と管理画面通知でリマインドする。期限切れ、または受付終了までに枠取り直しが終わらない場合は `voided` になり、本人向けには「不備」と表示する。
    - **未予約時**: 「現在開催中のイベントがあります。枠を予約しませんか？」というプロンプトとエントリーボタンを表示。

### 3. マイ・ギャラリー
*   **役割:** 過去に投稿した全ての資産を管理する。
*   **構成:** 連携している X ID ごとにタブまたはセクションを分けて表示。
*   **機能:**
    - 各作品のカードには、現在の `status`（公開済、審査中、非公開等）を表示。
    - `x_reapply_required` の作品は「調整中」として表示し、作品本文・YouTube URL・合作メンバー・クレジットは編集可能にする。
    - `voided` の作品は通常のギャラリーには混ぜず、通知からのみ「不備」として確認させる。復旧は管理者専用で、ユーザー本人が同じ動画を再登録する場合は別作品として扱い、旧コメントやチャプターは引き継がない。
    - 作品ごとのクイック編集（`/dashboard/edit/[id]`）導線。

### 4. エンゲージメント・スタッツ
*   **役割:** 自身の活動に対するポジティブなフィードバックを与える。
*   **内容:**
    - 全作品の「合計いいね数」「合計再生数」をダッシュボードのサイドまたはトップに統計チップとして表示。
    - 投稿した作品数、企画に投稿した作品数、自分で登録した作品数を別項目として表示。
    - 「最近いいねされた作品」などのマイクロ通知。
    - Cloudflare/R2 の保存容量情報は一般ユーザーダッシュボードには表示しない。

### 5. 運営お知らせ
*   **役割:** 運営からの重要事項や Discord への誘導。
*   **内容:** 静的なお知らせメッセージ、またはイベント締切までのカウントダウン。
