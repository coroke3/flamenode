## Owner decisions (DECIDED 2026-10-24, owner-delegate Fable)
- SP-1 DECIDED: MAX_SPREADSHEET_PAGE_ROWS = 50 (default and cap; ADMIN_SPREADSHEET_PAGE_SIZE is clamped to 50; /tables pageSize is 50). events at 50 rows is 43,280 B, close to the 48 KiB budget; 99 would make byte drops the norm.
- SP-2 DECIDED: (a) partial export is adopted in this PR (MAX_SPREADSHEET_EXPORT_ROWS = 99, 48 KiB, X-Spreadsheet-Truncated: 1 and the `-partial` filename). (b) a `/export` `page` parameter (same offset semantics as /data, offset = (page-1)*99) is a cutover prerequisite follow-up for RH-007 (U02 write half or its own micro-unit). (c) Queue + R2 export is rejected (admin only, low frequency, Free tier).
- SP-3 DECIDED: drop whole rows (never cut cells) and return truncated: true with hasMore: true. Cell truncation is rejected because it changes the write contract. The Ops UI (MIG-0705 U06) must lower `limit` to the kept row count (minimum 1) and continue paging. A single row over 48 KiB is a known unreadable gap (follow-up: single-row read by PK or a readonly cell marker; the owner decision remains).
- SP-4 DECIDED: the qualified form `pragma_table_info(sqlite_master.name)` is adopted (unambiguous on every SQLite version). Remote D1 verification is a pre-cutover smoke (owner operation): /tables returns the 48 schema tables. Fixing CURRENT discovery.ts:48 is outside this MIG (optional separate PR).
- SP-5 DECIDED: unexpected errors return the fixed { error: "internal_error" } with 500, and every response is private no-store; unknown_table 400 and db_unavailable 503 keep the CURRENT codes.
- SP-6 DECIDED: setting the ADMIN_SPREADSHEET_ENABLED Worker var is an OWNER operation (Worker/secret operations need explicit approval). apps/api has no wrangler config, so where it is set is decided by the deploy task; it goes on the cutover checklist and agents do not do it.
- Routing condition (DECIDED): Worker Routes cannot split by method (ROUTING_AND_DEPLOY_PLAN.md:77), so pointing /api/admin/spreadsheet/* at Hono is allowed only after the U02 write half (RH-004/005/006/008) merges; until then Next serves all methods and this PR's code is unreachable in production.
