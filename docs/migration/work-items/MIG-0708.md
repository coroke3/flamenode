## 2026-11-09 image upload MIME fail-closed client guard

- The icon file picker had `accept="image/png,image/jpeg,image/webp"` and an 8 MiB check, but browser `accept` is advisory and does not enforce file types. A user could pass a `text/plain`/other unsupported blob to `uploadIcon` from the isolated U03 control.
- Added a MIME allowlist before upload (`image/png`, `image/jpeg`, `image/webp`); unsupported or empty MIME is rejected with a user-facing message and the input reset.
